# In-silico — when modifying (the bodies)

> **Auxiliary file of the `in-silico` skill. Read this before editing a script, a shared constant, a
> cache or a doc that quotes one.** The one-line index in `SKILL.md` §When Modifying is the carrier;
> this file is the mechanism, the incident that bought it, and its bounds. Edit rules HERE — the
> index is generated (`ruby scripts/guard_craft_index.rb --write`).
>
> **Numbered on 2026-09-18, append-only from then on.** Before the split these were unnumbered
> bullets, so older citations name the section (`§When Modifying`) and never a number; the numbers
> follow the pre-split order.

1. **Adding a ligand is a five-step chain, and skipping the last step leaves downstream MD stale**: script 0N (parameterize) → add to gaff_cache → SDF to ligands/ → add test → rerun downstream MD

2. **Change a SHARED or canon-mirrored constant only in `tools/in_silico/lib/constants.py`, then find every cached JSON that used it — a coefficient private to one script's model changes in that script.** A value can also have a C# consumer: what `66` measures is mirrored in `tools/cad` (`TopologyCrossChecks.NetworkThicknessPerPeriod`), where no Python re-run reaches it — chase it there too. 🔴 **And the mirror runs BOTH ways, which is the half this rule lacked until 2026-09-21** (`00_07` HW.26): `55_bus_mechanical.lock_insertion_window_mm` re-implements `MechanicalLock.InsertionWindowMm` BY VALUE, so a verdict applied in `tools/cad` leaves the Python half measuring a geometry that no longer exists — it did, for three days, until the in-silico window still ended at the DIN-471 groove that the verdict had already made non-binding. ⛔ No gate spans the pair and none is cheap: both halves read the SAME manifest, just different fields, so a pin on the manifest stays green through the divergence. **Reflex when a CAD verdict lands: grep `tools/in_silico` for the manifest key it retires, not only for the value.**
   🔴 **Since 2026-09-21 «find every cached JSON» has a GATE behind it for part of that set, and knowing WHICH part is the point** (`00_07` DOC-T.117). `test_constants_match_kinetics_output` and `test_constants_match_mechanical_output` in `tools/in_silico/tests/test_cache_integrity.py` assert that the committed cache field still equals the constant it was computed from — so editing `ETA_BQ`, `SLM_MIN_WALL_DEFAULT_MM` or `SWAY_F0_HZ_*` without re-running its script now REDS, where before the whole suite stayed green (measured by mutation; the positive control `KM_GLUCOSE` reddened, so the zeros were real). ⚠️ **Two limits, both load-bearing.** (a) The pin judges COHERENCE, not the canon binding: a value that is arithmetically right under a foreign referent passes it, which is the `HW.45` class. (b) **`D_BUS_ROD_MM` is deliberately NOT pinned and must stay unpinned** — pinning this file's frozen-geometry mirrors was measured and REFUSED (⚖️ founder 2026-09-09, `00_06 §2`); adding it rebuilds what was declined. Adding a NEW shared constant? Ask which half it is in before reaching for the pin.

3. **After any change run the in-silico tests, commit, then update every SSOT doc that quotes the result**: `pytest tools/in_silico/tests/` → commit → update the SSOT docs listed at the top of `SKILL.md`

4. **Drift-proof comments/constants — never hardcode a mirror of another script's result; LOAD it from that script's cache JSON at runtime** (crude t_ij, single-snapshot β·d, an E°; 24b/28b do this) so it can't silently diverge. A **DERIVED aggregate (a Hammett LFER slope / fit) must ALSO be computed INTO the cache** (21e writes a `lfer` block), else cache-vs-doc tooling has nothing to diff against — and a consumer takes the fit-set FROM that block (`lfer.fit_set` / `lfer.excluded`, as `60` does), never re-picks it: which points enter a fit is part of the result. 🔴 **And the rule is NOT about numbers only: a PROSE claim about another script ages exactly the same way, and worse, because no diff of yours ever touches it** (2026-09-22, `00_07` HW.5.IS). A provenance line typed as «script 35 has no Cu row» was true the day it was written and turns false at that script's first FULL run — its `which = … or list(METALS)` includes the metal, and the unphysical branch still emits a row. The NUMBER was safe (the fallback is hard-coded and never reads that cache); the SENTENCE was not, and it is both printed to the operator and quoted by canon. **Derive such a line FROM the other script's cache at runtime and enumerate the STATES — no row · a row flagged unphysical · a row that PASSES its own physicality check — announcing the last one loudly, because that is the state which makes your fallback stale.** ⊕ **When the quantity you need is NOT in the cache — a full series the producer only SUMMARISES — recompute it with the producer's OWN code (importlib) and refuse to run unless that code reproduces the producer's cached summary** (`78` → `71`: the hourly capsule temperature is never written, only its 30-year maxima are; `78` re-solves it through `71`'s functions and exits if any max differs from `capsule_envelope.json`). Same code = no second home; the equality check = a producer edited without a re-run cannot feed you a series its own cache does not stand behind. ⊕ **Reproducing a producer's cached EXTREMUM takes the producer's SET, not a finer one** [`105` ⊥ `103`, 2026-10-21]: `103`'s share caps are maxima over its own depth grid; a 0.5 mm grid landed on the composite run's end and found a max 1e-4 higher — the reproduction check failed on the set, not the model. Read the producer's grid from its code and use it verbatim; if the true extremum matters to you, compute it separately and name it as another set.

5. **A cache PROSE field (`verdict`, notes) is what docs quote — build every factual clause from the computed data, never type it.** A re-derived console report does not re-derive the cache string: `55`'s cache `verdict` contradicted the numbers in the same JSON for a day after its inputs moved (`00_07` HW.34). Grep the cache's prose for every count and comparison it states. ⊕ **A verdict FLAG must test every criterion its verdict sentence prints, or split into one flag per criterion:** `51`'s per-row `safe` judged hoop stress only, beside a verdict that also claimed the interference held — now `hoop_below_peek_yield` + `interference_retained_at_band_min`. ⊕ **When the finding IS a sign, the sign must be read, never typed — and it hides in six places at once** (`00_07` HW.5.IS, 2026-10-16, the 1,5-dihydro recompute turned the B3LYP-Koopmans cascade from −1.05 to +0.07 eV): a format `+{x}` (Table 2 would have printed «+-0.079»), a typed label («(uphill)» beside +0.068 on Fig 3), an `abs()` that drops the sign, axis limits drawn around the old levels (half the series fell off Fig 3b silently), a pin's number class without `+` (the cell reads as ABSENT, not as drift) and an anchor that carries the moving value as context. Only the first two would have been loud, and only because a canon-drift constant stopped the generator; the axis would have shipped. 🔑 Reflex: when a recompute can cross zero, grep the generators for `+{` · `abs(` · `set_ylim(` · `uphill`/`downhill` and the pins for number classes without `+` before the run, not after. ⊕ **The same holds for the DOC's prose: a numeric pin never sees a sentence that names a SET or a DIRECTION («Ta only», «every alloy but Ta», «rises at none», «falls with moisture»), so such a sentence gets a test that RECOMPOSES it from the cache** [`106`, HW.23, 2026-10-21 — three adversary rounds]. Every set or direction sentence written into a fix by hand that round fell to the next round or to a direct check (a trend taken from 65 % RH instead of the source's first group; «a stiffer alloy takes a smaller share», false on 20 cells once an alloy's ν enters); what stood was the sentence the test rebuilds — `test_share106_categorical_sentences_follow_the_cache`. Write such a sentence FROM the field that tests it, in the same step. ⊕ **And when a cache flips an ORDER (which of two readings is the lower, which column is conservative), the old order survives in places no sentence test reads: table HEADERS («lower ⊥ higher reading: axial ⊥ radial»), a parenthesis that labels a column («`105`'s lower reading»), a clause that names the conservative side** [`105`/`106`, HW.23 re-sweep, 2026-10-23 — the lower reading moved from the axial to the radial one; every composed sentence followed, four static labels did not, and the one pin that had held «0.7 % stiffer» was deleted instead of re-aimed; an adversary found all four]. On a flip, grep the docs for the old order's WORDS (`lower` · `higher` · `conservative` · `stiffer` · `softer` · `axial ⊥ radial`), derive each header and label from the cache in a test, and re-aim — never delete — the pin that carried the flipped figure.

6. **Its numeric twin: a cache NUMBER rounded for display is OUTPUT — never compute FROM that row.** In `55` rounded rows fed three downstream blocks, one quantity carried two values in one cache, and the rounding manufactured a «robust» verdict that the exact member turned into a tie (`00_07` HW.34). Take the member from its definition (`branch_member()`); pin that two owners of one quantity agree; before calling a verdict on a third-decimal margin robust, re-derive it at the precision it was born with. ⚠️ The LOAD-from-cache rule (§When Modifying #4) inherits whatever precision the writer stored — ask what that was before computing from it. ⊕ **The class travels by the READER, not by the field a leg names** (`87`, `00_07` HW.43, 2026-11-02): the leg named the stem strain; listing what each reader of the cache takes found the acceleration, the imposed shift, the O-ring need and the mass ceiling computed from after rounding too, a first list keyed on the row the leg named missed the last (it sat in `inputs`), and only the adversary found the rest — the seam requirements that `87`'s own verdict and `102` round AGAIN, one-sidedly, the coaxial ratio the verdict computes from, and the inputs the cache-integrity test recomputes from (their rounding, with the need's own, is why its tolerances stood at 0.02 N and 0.1 g). So list, per consumer — a test included — every field it reads and ask of each «computes from it, or only quotes it?»; a quote that is rounded again is a computation. Then a doc pin with zero tolerance on the displayed number applies the DISPLAY's own rounding to the raw value — nearest for a reading, up for a requirement «≥ X», down for a floor (the helpers of `tools/in_silico/tests/test_doc_cache_sync.py`) — never raw. ⊕ **The class travels UP the cascade too, and there it was larger** (`52` · `55` · `71` · `73` · `78` · `88` · `89` · `90` · `102` · `103` · `110` · `111`, `00_07` HW.43, 2026-11-03): the leg named three writers inside the cascade, but its readers computed from the rounding of writers one link ABOVE it — `55`'s press-fit friction cached to 0.1 N (7.5·10⁻³) under the grip the leg priced at ±2.3·10⁻⁴, `90`'s margins to 0.1 µm, `71`'s hot edge — so inventory by what each reader ACTUALLY reads, every cache, not by the cascade's own. Two instruments turn that inventory into a measurement: a raw TWIN of each writer (`round(x, n)` replaced by a float that serialises raw but compares and formats as the rounded value, writes redirected) diffed against its cache names every rounded leaf, and a TRACE of each reader (its cache leaves wrapped to record compute · compare · round · format · copy) names who computes from it; their product is the class over the caches you twinned. Their blind spots, each a finding the adversary of that pass made: the twin breaks the `round(x, 9)` guards inside floor/ceil helpers and once manufactured a display move (`104`'s «12.0 → 11.9», absent from the real re-run); a copy taken from an upstream rounded cache shows only at the upstream twin, so a writer left untwinned hides its copies (`68` → `86` → every seam k); a whole dict cached as a quote escapes a grep for field names (`84`'s copy of `78`'s bark bracket); and a number parsed back out of a LABEL is a reader of the display the trace cannot see — making `102`'s thresholds raw turned `103`'s `f"cold_flip_{x:g}"` key into a six-digit display its bisection then targeted, a new instance the pass itself made. Carry the value beside its label. Raw values then EXPOSE degenerate roots the rounding hid — the wall `88` requires at the window top tolerates exactly k = 0 there, since that point defines it (rounded, it showed 0.072 N/µm; the ratified 0.28 mm wall is another quantity and has room), `103`'s free sleeve stretches exactly its free length (rounded, 0.0 hid 2.2·10⁻¹⁵): return those exactly (#32), never a tolerance; and a TEST can cement the artifact — the cache-integrity test asserted «δ binds harder» on the two manufactured k_max, so the property moved to the squeeze where it is not degenerate. A control whose tolerance was the rounding (0.05 · 2e-3 · 2e-4) tightens to the precision its reproduction MEASURES once both sides are raw — 1e-9 where the same code reproduces the number, ≈ 1e-7 for `105`'s independent closed forms of `103`'s solver — and its old «miss» reading was the rounding itself. Making a field raw also moves every number in canon that pins it: check each edited token against the ⚖️ block or ⊕ дописка it may sit in before writing — a preserved form keeps its number and gets a dated ⊕ beside it, and the pin moves to the ⊕ (`02_02 §3.5` «(г)», `01_01 §1.4` Ti-15Zr; `00_05 §7`).
 ⊕ **Making a writer raw turns every FORMAT of its value into a reader** [`68` → `86` chain, HW.43, 2026-11-05]: `f"{x:g}"` or a bare `{x}` printed the cached rounding for as long as the cache was rounded, and prints 6–16 digits the moment it is raw — `92`'s verdict would have read «k ≥ 0.388198», and `91`'s summary DID ship «68's 3.396557892480503 MPa» into its cache. The first fix, `round(x, 2):g`, printed «3.4» — and the adversary caught that the ratios beside it (×1.004–1.022) are taken against the RAW value, so a reader dividing by 3.4 gets ×1.003: **a value that is the DENOMINATOR of printed ratios prints at their precision** (`{lo:.3f}` → 3.397), and so does every doc copy (SUMMARY called it «`68`'s figure» while the nearest `68` number on the page was a bracket's 3.40). Before re-running downstream, grep each reader for the raw writer's fields inside f-strings — a value first bound to a local name escapes a grep for the field, so the non-numeric class of the cache diff (#15) is the net that catches the rest.
7. **A contact station read off the FREE shape at FULL load is not an equilibrium.** Under a tip load the deflection grows monotonically from the clamp, so the first station to reach a uniform wall is the FARTHEST one, and from then on the load is reacted there. Before quoting a contact station, ask whether the shape it came from is still admissible once the contact exists — and solve the contact (`tools/in_silico/lib/beam_contact.py`, one home for `55` and `68`, `00_07` HW.34). ⊕ One level down, a rigid-wall answer is only one END of a bracket, because the real wall (the polymer on the Ti bore's edge) yields: carry the BRACKET in cache fields (`sliding_in_contact_um_rigid_kinematics` ⊥ `sliding_in_contact_per_cycle_um_upper`) and give every rigid-wall figure its SIGN (`coaxial_root_bound: LOWER…`, `reaction_bound: UPPER…`). 🔑 **A bound quoted without its sign becomes a nominal:** a «capped at» that was really the LOWER end flipped a finding, not a digit. A quantity read off a shape must be re-asked once the shape is constrained — and once the constraint is found to be soft. ⊕ **Compliance signs each quantity separately** (`77` Q2, 2026-10-03): coupling rigid parts at their centroids OVERSTATES the demand — the moment that would stop the relative motion, since compliant parts take the medium's deformation with their own — but only REDISTRIBUTES the relative motion: a part that follows its local medium (decay length ≪ its length) puts the motion's PEAK at its free end, above the centroid figure (1.56× there). «The real slip and demand are lower» was half wrong and read as one sentence; ask the direction per quantity, and carry the peak factor as a cache field. The same holds for a DIFFERENCE of two columns (`79`, same day): clear sky and no sun are the coldest case for both the bark and the flange column, and the case MOST FAVOURABLE to the flange for their shift. Called an upper bound, that case gave the canon «the direction mostly survives»; with cloud or sun added, the sign flipped. An input extreme for each operand is not an extreme for their difference, so take the difference to its own ends. ⊕ **And a quantity read at FULL load is not the cycle's PEAK** (`91`, HW.34, 2026-10-14 — caught by an adversary, not by any control). Wherever the reaction sits inboard of the point the load is applied at, its lever grows as the load grows past touchdown, so the root moment FALLS through the contact phase: full drag was the MINIMUM, and the peak sat AT touchdown, where the reaction is zero — the elastic and the rigid wall coincide there, so a compliance cannot act at the peak at all, and its real effect (on the loaded part, against a rigid wall at the SAME edge) had the opposite sign to 68's 3EI·(R/k)/L². The full-drag table had published «at or below the rigid end» — right about the endpoint, wrong about the cycle. A fatigue question asks for the extreme over the PATH, never its endpoint: solve the path from first contact to the largest load, and carry the peak, the load it sits at and the sub-cycle range as fields (`cycle[].peak_sigma_MPa` · `peak_at_drag_N` · `subcycle_range_MPa`); read every decomposition on the SIGNED figure (a modulus stops being additive the moment the moment crosses zero). Sibling of the same table: a station SHIFT (an edge radius moving the contact inward) and the compliance were folded into one «position in the bracket» — compare with the rigid wall AT THE SAME EDGE before attributing a shift to the give. ⊕ And split the effect where the model is LINEAR in what you attribute: a «share» read at the model's own patch centroid hides the compliance inside the centroid's position (round 2 of the same review) — the honest reference is the rigid wall at the same EDGE, never at a station the elastic solve itself chose.

8. **A control that cannot fail is not a control — say in the docstring what each assert CAN and CANNOT catch.** `68` first shipped an equilibrium assert that is an identity of the stiffness matrix's rigid-body null space (it passes with EI doubled or the mouth moved) and a mesh check on rows whose contacts sat on nodes, where Hermite elements are exact. What catches real defects is a control with an INDEPENDENT formula or a location the solve does not enforce: closed forms at the pad plane and at the mouth, and the wall tested at element MIDPOINTS (which caught a mesh leaving the mouth between nodes on a new geometry). ⊕ Other direction: a claim carried as PROSE in a cache string («the root is the peak-moment section in every configuration») is a claim without a measurer until a field carries it — read from the moment field of every solve, it was false on two lock-window classes. ⊕ **A scheme check must excite the scheme's weak mode** (`79`, 2026-10-03): `78`'s check — a smooth 24 h wave on an imposed surface temperature — is right for its scheme and blind to the next one. Crank–Nicolson with an energy balance on a surface half-cell (Fourier number ~10³ per substep) rings: 11.8 % off the closed form 6 h after a STEP (Incropera eq. 5.60), first seen as a cambium colder than its own surface. The wave check would have passed; the step check failed. Moving a boundary from imposed to balanced is a new weak mode and needs its own check — there: implicit stepping, with the step and the wave both as runtime gates. ⊕ **A solver check must run in the REGIME the model uses, not in a limit where the method is easy** (`84`, HW.53, 2026-10-11): a thin-wire segment solver for the anode's spreading resistance passed its control — the slender-rod closed form within 2 % at L/a = 1000 — while at the anode's own L/a ≈ 7.3, with segments 0.1 mm on a 5.5 mm radius, the first-kind integral equation was singular (condition number ~5e17, negative charge densities, the factor jumping with depth and N); an adversary found it, not the control. The fix that held: a method that stays well-posed at the operating geometry (axisymmetric finite volumes) and a control with an EXACT answer in the same regime and the same code path — a sphere above a conducting plane, the sinh series — plus grid convergence at the operating point. ⚠️ And mutation-test with a real defect: a discretization variant that vanishes under refinement (face midpoint → node, < 1 %) passing a 1.5 % control is not a blind control; a broken link area (π dropped) is, and it failed with numbers. ⊕ **A comparison against another cache that SKIPS the rows the cache lacks is a control that can pass with nothing compared** (2026-10-28, `78` at 71's `h_c × 0.7`): `want = cache.get(key); if want is not None: compare` checked 2 of 6 α rows — 71 caches only the ends of its sweep — and a key-format change would have made it compare zero and stay silent. Count what was compared and assert it equals what the reference holds; print which rows stayed unchecked.

9. **A solver loop needs an explicit non-convergence branch (`for … else: raise`, plus a cycle detector on an active set), and its tolerances come from the MEASURED solve precision.** A solver with an iteration cap and no `else` can hand back a non-converged state as a number; the committed one refused on a cycle, which exposed a violation tolerance below the solve's own precision re-picking an already-active node. Measure the precision first and write it beside the tolerance (as the docstring of `tools/in_silico/lib/beam_contact.py` does).

10. **A literature constant that does not EXIST at your conditions is not a number to pick — bound it by SIGN, then price it.** `67` (HW.3) needed calcium and magnesium malate complexes at I = 0 that no open primary has (only APPARENT constants from another medium); electing one would have rested the whole admissible window on it. The sign needs no value — a calcium ligand left out can only RAISE the calcium-oxalate SI, a magnesium ligand can at most free what magnesium holds — so a HARD BOUND (those ligands off, magnesium oxalate-inert, the documented constants at their SI-raising ends) carries the window, its dominance over every documented reading is ASSERTED at every corner, the readings PRICE the gap instead of hiding it, and the verdict side inverts into a break-even constant (same family as `55`'s `WELD_KNOCKDOWN_MEASURED = None`). ⚠️ **A bound is a bound for the ONE quantity it was built for** — every other number a bounding scenario prints is an artefact of the switch you threw (this one reported magnesium oxalate SUPERSATURATED, having made magnesium oxalate-inert by construction). 🔴 **Follow the sign through EVERY channel the constant acts on, not by mass action alone:** a neutral magnesium complex also takes two divalent ions out of solution, raising the activity coefficients of Ca²⁺ and ox²⁻ and so the SI. The fix was structural, not a caveat: the bound takes that channel's limit (every magnesium ion sequestered), and dominance is asserted against each missing constant SWEPT to strong values — a documented reading is not the edge of what the constant could be.
