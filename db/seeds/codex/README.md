# Codex — культурний корпус (без рантайму)

Це **дані, не машина**. YAML тут пережив зріз рантайм-шару Codex 2026-08-15 за
прямим рішенням founder'а: корпус і машина роздільні, і корпус переживає
зникнення всіх таблиць, моделей та імпортерів.

**Чого тут НЕМА і не має бути:** таблиць `codex_*`, моделей `Codex::*`,
імпортерів (`NodeImportService` / `DiscoveryRuleImportService`), маршрутів,
компонентів, локалей. Усе це знято. `db/seeds.rb` цей каталог **не читає**.

**Що це таке.** Чотири реалми (`realms.yml`) і корпус вузлів під ними
(`nodes/*.yml`): екосистеми, іменовані дерева, біопротоколи, міфологія. Плюс
`discovery_rules.yml` — правила з мертвого шару відкриттів, лишені як запис
задуму, а не як конфіг.

**Стеля, названа явно.** Читач у цих файлів **один** — `db/seeds.rb` бере з `ecosystems.yml` чотири OSM-верифіковані ліси Черкащини (назва + координати; з 2026-09-03, UI.19), решту ніхто не читає; валідатора ключів
(`Codex::ARCHETYPES`) більше не існує, тож ніщо не почервоніє, якщо корпус
зіпсувати. Це свідома ціна: гейт на дані без споживача був би важелем без
пускача. Хто повертатиме шар або братиме корпус в інший бік — читає підставу
зрізу в [`00_07`](../../../docs/00_07_Action_Plan_Tracker.md) UI.15, а не
відновлює механіку за цими файлами.
