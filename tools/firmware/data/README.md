# Сонце на горизонтальну поверхню — клітинка Черкас, добово, 2001–2020

**Для чого:** генерація панелі Королеви в `tools/firmware/queen_energy_budget.rb`. Доти модель брала «години сонця зимового дня»
сталою без джерела; у її формулі `панель × години × ККД × частка під кроною` «години» — це добовий потік у площині панелі в
кВт·год/м² (еквівалентні години при 1 кВт/м²), і цей ряд дає його по добах для горизонтальної поверхні.

**Провенанс — запит, а не лише результат** (взято 2026-11-13 через `curl`):

```
https://power.larc.nasa.gov/api/temporal/daily/point?parameters=ALLSKY_SFC_SW_DWN,ALLSKY_SFC_SW_DIFF,CLRSKY_SFC_SW_DWN,ALLSKY_SFC_UVA,ALLSKY_SFC_UVB,PSH,ALLSKY_SRF_ALB,SNODP,FRSNO,T2M_MIN,T2M_MAX,WS10M_MAX,PRECTOTCORR,IMERG_PRECTOT&community=RE&longitude=32.06&latitude=49.44&start=20010101&end=20201231&format=CSV&time-standard=UTC
```

NASA POWER Daily API. Рядки шапки відповіді про два взяті стовпці, дослівно:

```
NASA/POWER Source Native Resolution Daily Data
Dates (month/day/year): 01/01/2001 through 12/31/2020 in UTC
Location: latitude  49.44   longitude 32.06
ALLSKY_SFC_SW_DWN      CERES SYN1deg All Sky Surface Shortwave Downward Irradiance (kW-hr/m^2/day)
ALLSKY_SFC_SW_DIFF     CERES SYN1deg All Sky Surface Shortwave Diffuse Irradiance (kW-hr/m^2/day)
```

Точка 49.44 N 32.06 E — та сама, для якої `tools/in_silico/data/era5_cherkasy/` питали ERA5.
`power_cherkasy_sw_daily_2001_2020.csv` — 7 305 діб без пропусків (значення пропуску у відповіді — `-999`, у цих двох стовпцях його
немає): стовпці `ALLSKY_SFC_SW_DWN` і `ALLSKY_SFC_SW_DIFF` відповіді під назвами `ghi_kwh_m2` і `diffuse_kwh_m2`, дата зведена з
`YEAR,MO,DY` в ISO, значення — як у відповіді, без округлення. Решту стовпців відповіді у файл не взято; сира відповідь у дереві
не лежить.

**Температура для заборони заряду — не з цього файлу.** Модель блокує заряд акумулятора на добах, холодніших за поріг
`02_05 §4а.5`, і бере для цього добову середню температуру повітря ERA5 тієї самої точки —
`tools/in_silico/data/era5_cherkasy/daily_t2m_mean_1991_2020.csv` (провенанс — README того каталогу). Доба там — за київським
часом, тут — за UTC: межі діб розходяться на дві–три години.

**Чим цей ряд НЕ є:**
- **Не вимір на ділянці.** Потік пораховано з супутникових хмар і профілів реаналізу на клітинці 1°; точність добового потоку з
  первинки продукту тут не прочитано.
- **Не потік на панель.** Це горизонтальна поверхня під відкритим небом. Нахилена панель на відкритому місці взимку збирає більше
  прямого світла; яка частка світла під кроною розсіяна і чи дає там нахил хоч щось — ряд не каже.
- **Не світло під кроною.** Частку, яка доходить до панелі крізь крону, модель множить окремим параметром `canopy_pct`; джерела в нього
  немає, і ряд його не дає.
- **Не сніг на панелі.** Сніг, іній і бруд сидять у `panel_eff`.
