## 🛑 Блокери (Blockers / Needs Action)

### 🟡 BLOCKER-1: Ліцензія nTop (Mid-Priority)

**Статус:** Очікується. Ліцензія nTop необхідна для генерації TPMS (Triply Periodic Minimal Surface) гіроїдної геометрії з точними параметрами (65% пористість, розмір комірки, двоступенева шорсткість). Альтернативи: Rhino + Grasshopper (безкоштовно), але складніше у налаштуванні для нашої специфіки.

**Необхідна дія:** Очікуємо ліцензію → завантажити nTop → згенерувати STL/STEP файл анкера → передати на DMLS-завод.

### 🔴 BLOCKER-2: Розрахунок Допусків Press-Fit (High-Priority)

**Статус:** Критичний. Без точних мікро-допусків для гідравлічного пресування (Press-fit) титану в PEEK ізолятор може тріснути під час монтажу анкера в дерево під кутом 30°.

**Необхідна дія:** Розрахувати допуски (кількість мкм натягу для Ti→PEEK press-fit) та верифікувати тестовим пресуванням.

## 📎 Технічна Специфікація: Анатомія "Матрьошки"

Анкер довжиною 120 мм складається з трьох окремих деталей, які виготовляються різними методами і збираються на заводі в єдиний моноліт.

### 🔵 Деталь 1: Катод / Нижня частина (Titanium Ti-6Al-4V)

- **Технологія:** SLM / DMLS 3D-друк (DMLS-виробники: Київ, Дніпро, оптова партія 100 шт.)
- **Структура:** Пористий TPMS гіроїд із тупим заокругленим кінцем (для м'якого розсування волокон ксилеми, а не різання)
- **Спеціальна геометрія (Стрижень):** З геометричного центру гіроїда вертикально вгору виходить суцільний титановий стрижень
- **Анти-ротація:** Стрижень має **шестигранний** (або шліцьовий) профіль, що запобігає прокручуванню деталей під час монтажу. Передає "Мінус" від нижніх ферментів до верхівки анкера.

### 🟡 Деталь 2: Ізолятор (Medical Grade PEEK)

- **Технологія:** ЧПУ-фрезерування (CNC) із суцільного стрижня
- **Матеріал:** Polyether ether ketone (PEEK) — абсолютно біоінертний, міцний діелектрик
- **Структура:** Шайба/втулка з внутрішнім шестигранним отвором, що ідеально повторює профіль стрижня Деталі 1. Розділяє катодну та анодну реакції.

### 🟢 Деталь 3: Анод / Верхня частина (Titanium Ti-6Al-4V)

- **Технологія:** SLM / DMLS 3D-друк
- **Зовнішня геометрія:** Широка різьба по дереву (для надійної фіксації) та макропориста гіроїдна секція внизу для інтеграції з калюсом (CODIT)
- **Внутрішня геометрія:** Порожнистий шестигранний канал (трубка), куди вставляється Деталь 2 (PEEK) разом зі стрижнем від Деталі 1. Стінки трубки **не торкаються** внутрішнього стрижня.
- **Верхівка (Шляпа):** Шестигранний шліц під ключ формату М6 для закручування.

## 🎯 Сліпе Сполучення (The Blind Mate Target)

Найважливіша частина CAD-моделі — верхня площина анкера (шляпа М6), з якою контактує капсула електроніки:

1. **Центральна точка (GND):** Верхівка внутрішнього стрижня (Деталь 1) → центральний Pogo Pin від BQ25570
2. **Ізолююче кільце (PEEK):** Тонкий шар пластику між полюсами
3. **Зовнішнє кільце (VIN DC):** Поверхня шляпи М6 (Деталь 3) → зовнішній Pogo Pin

---

## 🏭 Заводська Збірка (Assembly Protocol)

1. На шестигранний стрижень Деталі 1 напресовується Деталь 2 (PEEK)
2. На цю конструкцію зверху напресовується Деталь 3
3. Уся збірка поміщається під гідравлічний прес. Тертя і шестигранний профіль → вічне механічне з'єднання
4. Арборист отримує монолітну 120-мм деталь і вкручує її в сосну як єдиний суцільний цвях. Жодних дротів у лісі.

## 📐 5. Ізоеластичність TPMS-Гіроїда (Isoelasticity Specification)

### 5.1. Проблема Stress-Shielding

При вживлянні жорсткого металевого імплантату в деревину виникає ефект **stress-shielding**: металевий стрижень бере на себе основне механічне навантаження (вітер, гойдання дерева), розвантажуючи навколишню ксилему. Це спричиняє:
- Атрофію ксилемних судин навколо анкера (аналогічно остеоатрофії навколо жорстких кісткових імплантатів)
- Розрив між деревиною та анкером з часом
- Відмову CODIT-інтеграції (kallus не розростається навколо жорсткого інородного тіла)

**Рішення:** Пористий TPMS-гіроїд із пористістю 65% має **макроскопічний модуль пружності 13–15 ГПа** — у точному відповідності до модуля пружності деревини дуба та сосни (9–16 ГПа).

### 5.2. Специфікація Ізоеластичності

| Параметр | Значення | Обґрунтування |
|---|---|---|
| Пористість TPMS-гіроїда | **65%** | Оптимум: максимум ізоеластичності + достатня механічна міцність |
| Макроскопічний модуль Юнга (E) | **13–15 ГПа** | Матчинг з деревиною Pinus sylvestris (9–16 ГПа) |
| Модуль Юнга суцільного Ti-6Al-4V | ~110–120 ГПа | Базовий матеріал |
| Коефіцієнт зниження (ефект пористості) | ~7–9× | Закон Gibson-Ashby для пористих металів |
| Межа міцності на стиск (65% пористість) | ~25–40 МПа | Достатньо для довгострокової інтеграції |

**Розрахунок за законом Gibson-Ashby:**
```
E_foam / E_solid ≈ C × (ρ_foam / ρ_solid)^n

де n ≈ 2 для відкритопористих структур (TPMS гіроїд)
C ≈ 1.0 (для TPMS, вища ніж для нерегулярних пін)

При 65% пористості: ρ_foam / ρ_solid = (1 - 0.65) = 0.35
E_foam ≈ 1.0 × (0.35)^2 × 110 ГПа = 0.1225 × 110 = 13.5 ГПа ✓
```

**Перевірка через діапазон:**
- При 60% пористості: E ≈ (0.40)² × 110 = 17.6 ГПа (верхня межа)
- При 70% пористості: E ≈ (0.30)² × 110 = 9.9 ГПа (нижня межа)
- **Оптимум 65%: E = 13–15 ГПа → ідеальний матчинг з деревиною** ✓

### 5.3. Чому Гіроїд (не просто суцільні пори)

| Структура | Модуль пружності | Ізотропність | Рівномірність течії соку |
|---|---|---|---|
| Суцільний Ti-6Al-4V | 110–120 ГПа | Ізотропна | ❌ Немає пор |
| Нерегулярна пориста структура | 5–20 ГПа (непередбачувано) | Анізотропна | Нерівномірна |
| **TPMS Gyroid (65% пористість)** | **13–15 ГПа** | **Квазіізотропна** | **Рівномірна (мін. поверхня)** |

**TPMS Gyroid переважає** за трьома критеріями одночасно:
1. **Ізоеластичність:** 13–15 ГПа → матч з деревиною → нульовий stress-shielding
2. **Рівномірний транспорт соку:** мінімальна поверхня Шварца забезпечує рівномірний капілярний потік у всіх напрямках
3. **Максимальна площа контакту ферментів:** дворівнева шорсткість (макро-пори + мікро-ями) → максимальний EBFC-струм

### 5.4. Верифікація (Exit Criteria для TRL 4)

- [ ] Генерація 3D-моделі у nTop: перевірити пористість (65%) та симетрію гіроїда
- [ ] FEA-симуляція у ANSYS або Abaqus: підтвердити E = 13–15 ГПа при 65% пористості
- [ ] Після отримання першої тестової партії: нанотвердоміром або мікроіндентором виміряти E безпосередньо
- [ ] Тест монтажу під кутом 30°: переконатися, що гіроїд не ламається при вкручуванні

### Симуляція до отримання деталей (Virtual Prototyping)

**Поки фізичних деталей немає** — час для віртуального тестування:
- **LTspice** (Analog Devices, безкоштовний): симуляція аналогового ланцюга живлення (EBFC → LTC3108 → BQ25570 → Supercap) — перевірка струмів витоку та кривої заряду без ризику спалити реальні компоненти
- **KiCad** (open-source): проектування PCB для заводу — Gerber-файли для JLCPCB/PCBWay. Open-source статус важливий для грантових заявок
- **nTop** (після ліцензії): параметрична генерація TPMS-геометрії із заданою пористістю 65%
- **Wokwi** (хмарний): симуляція логіки STM32 та периферії до отримання плат
