# 02_03: BQ25570 MPPT та Нано-Менеджмент Живлення

---

## 🎯 Мета

Зафіксувати електричну схему, налаштування резистивних дільників та логіку роботи мікросхеми **BQ25570 MPPT** — єдиного менеджера живлення поточної архітектури. Документ описує конфігурацію восьми SMD-резисторів (VBAT_OV / VBAT_UV / VBAT_OK), відстежує виявлені проблеми з заводськими налаштуваннями Li-Po і встановлює цільові пороги для суперконденсатора 0.47F / 5.5V.

> **Архітектурна нотатка:** Step-up конвертер LTC3108 був **повністю виключений** із BOM під час ключового піво-ту (v2). Причина: EBFC вже генерує >500 мВ, що перевищує поріг Cold Start BQ25570 (330 мВ) — каскадний перетворювач LTC3108 більше не потрібен і видаляє 2 компоненти з плати.

Цей модуль є "травною системою" Солдата: він перетворює нестабільні мілівольти від біопаливного елемента (EBFC) на чисті 3.3V для STM32WLE5JC та LoRa-антени.

## 🛑 Блокери

### 🔴 BLOCKER-1: Відсутні Номінали Резисторної Мережі

**Статус:** Відкрито. Критичний. Блокує фінальну схемотехніку (Schematic Capture) та виробництво плат (PCBA).

**Суть проблеми:**

Мікросхема BQ25570 програмується **виключно апаратно** — через 8 SMD-резисторів із допуском 1%. Ці резистори встановлюють усі критичні пороги захисту: максимальну напругу заряду іоністора, поріг відключення при розряді та напругу активації мікроконтролера.

**Результат Hardware Audit:**

Модуль CJMCU-25570, що використовується в прототипі, є **готовим breakout-модулем** від стороннього виробника. За замовчуванням він постачається з резисторами, налаштованими на **заряд Li-Po акумулятора** (VBAT_OV ≈ 4.2V, VBAT_UV ≈ 2.0–2.3V). Наш суперконденсатор потребує принципово інших значень:

| Параметр | Дефолт Li-Po (CJMCU) | Наш Supercap (Цільове) | Різниця |
|---|---|---|---|
| VBAT_OV (стоп заряду) | ~4.2V | **5.5V** | +1.3V — критично |
| VBAT_UV (відключення) | ~2.0–2.3V | **3.0V** | +0.7–1.0V |
| VBAT_OK (увімкнення MCU) | ~3.0V | **3.4V** | +0.4V |

**Якщо резистори НЕ були замінені:** При підключенні до нашого суперконденсатора (5.5V) BQ25570 зупинить заряд на 4.2V, залишаючи ~25% ємності невикористаними (E = 0.5 × 0.47 × 4.2² = 4.14J vs E = 0.5 × 0.47 × 5.5² = 7.11J).

**В SSOT відсутнє:**
- Підтвердження того, що резистори на CJMCU-25570 були фізично замінені
- Конкретні номінали (значення в MΩ) та коди компонентів (E96-серія)
- Фотографія або схема модуля з позначеними замінами

**Необхідна дія:**
1. Виміряти мультиметром поточні значення резисторів на модулі CJMCU-25570
2. Зіставити з таблицею розрахунків з розділу 3 цього документа
3. При розбіжності — замінити SMD-резистори (0402, 1%) на розраховані значення
4. Зафіксувати фінальні номінали у цьому документі та схемі KiCad

**Блокує:** Finalization Schematic Capture, PCBA виробництво, Whitepaper hardware section, TRL 4→5.

### 🟡 BLOCKER-2: Коефіцієнт MPPT не верифікований для EBFC

**Статус:** Відкрито. Середній пріоритет. Потребує лабораторного уточнення.

BQ25570 використовує алгоритм Open Circuit Voltage (OCV) sampling: кожні 16 секунд на 256 мс від'єднує навантаження, вимірює напругу розімкнутого кола (VOC) та встановлює робочу точку як фіксований відсоток від VOC (налаштовується резисторами ROC1/ROC2).

- Для **сонячних панелей**: оптимальна точка ~80% від VOC
- Для **термоелектричних генераторів (TEG)**: стандарт 50% від VOC
- Для **ензимних біопаливних елементів (EBFC)** (Combi-CLEA на аноді + Laccase-AuNP DET на катоді): очікувано **60–70% від VOC** (НЕ 50%, на основі моделей Міхаеліса-Ментен та Тафеля — потребує емпіричної верифікації)
- **Поточна конфігурація:** 50% (ROC1 = ROC2 = 10 MΩ) — **ймовірно занадто низько для EBFC** (теоретична оцінка, потребує лабораторного підтвердження)

> ⚠️ **Критичне зауваження (Legacy notes):** Стандартні 50% (ROC1=ROC2) є нормою для TEG або класичних мікробних елементів. Але тризонний EBFC ([`01_03`](01_03_EBFC_Enzymatic_Bio_Fuel_Cell) §1) — Combi-CLEA `GOx+Catalase` / GDH на аноді (Zone 1) + Laccase-AuNP DET на катоді (Zone 3) — має **специфічну поляризаційну криву**: кінетика **Міхаеліса-Ментен** (ферментна реакція) та рівняння **Тафеля** (електрохімічне перенапруження) теоретично зміщують точку максимальної потужності (MPP) у діапазон **60–70% від VOC**. При 50% BQ25570 може просаджувати напругу занадто низько, заходячи в зону **масо-транспортних обмежень** ферменту, де дифузія субстрату (глюкози на аноді або O₂ крізь PTFE-GDL на катоді) стає лімітуючим фактором і потужність різко падає. **Потребує емпіричного підтвердження з P-V кривою EBFC.**

**Рекомендована початкова конфігурація для лабораторних тестів:** фракція **65%** від VOC:
- ROC1 = 5.36 MΩ (або найближчий стандартний: 5.36 MΩ 1% або комбінація)
- ROC2 = 10 MΩ
- MPPT_fraction = 10 / (5.36 + 10) = 0.651 ≈ **65%**

Точний коефіцієнт MPPT для нашого EBFC (Ti-6Al-4V | Combi-CLEA GOx+Catalase (Zone 1) + Laccase-AuNP DET (Zone 3) | ксилемний сік Pinus sylvestris) потребує **емпіричного уточнення** в умовах лабораторії ЧНУ або на тестовому стенді:
- Виміряти VOC та VMP при різних умовах освітлення (вранці/вдень/ввечері, сезонно)
- Зняти повну P-V криву (потужність-напруга) EBFC та визначити точну позицію MPP
- Підібрати оптимальну фракцію (очікується 60–70% для EBFC, починати з 65%)
- При необхідності скоригувати ROC1/ROC2

**Блокує:** Максимальна потужність EBFC, оптимальна швидкість заряду іоністора.

## ⚡ 1. Архітектурне Обґрунтування: Чому Спочатку Потрібен Був LTC3108?

### 1.1. Проблема Холодного Старту

Мікросхема BQ25570 — це надпотужний менеджер живлення, але вона має **фундаментальне обмеження**: для самостійного запуску (Cold Start) їй необхідна вхідна напруга не менше **330 мВ** та струм не менше 15 мкА.

Проблема: рання версія системи припускала, що EBFC на основі ксилемного потокового потенціалу генерує лише **44 мВ** (вимірювання на макеті з імітатором — резистивний дільник 3.3 кОм / 100 Ом від батарейки AA). Це в 7.5 разів менше, ніж потрібно BQ25570 для холодного старту.

### 1.2. Первісне Рішення: Каскад LTC3108 → BQ25570

Для подолання Cold-Start проблеми до системи був доданий **LTC3108** (Linear Technology / Analog Devices) — ультранизьковольтний підвищуючий конвертер, здатний стартувати від **20 мВ**:

```
Ранній прототип:
Tree Xylem (44mV)
      │
      ▼
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────┐
│ LTC3108     │────▶│ BQ25570      │────▶│ 0.47F       │────▶│ LoRa-E5  │
│ Meissner    │     │ MPPT Manager │     │ Supercap    │     │ STM32    │
│ Oscillator  │     │ (CJMCU)      │     │ (5.5V)      │     │ WLE5JC   │
└─────────────┘     └──────────────┘     └─────────────┘     └──────────┘
  1:100 xfmr          488nA idle           4.145J @ 4.2V      2.1uA sleep
  330pF resonant       VOC sampling/16s    Energy buffer       +22dBm TX
```

LTC3108 використовував осцилятор Майснера (Meissner oscillator) на трансформаторі Coilcraft LPR6235-752SMRC (1:100) та резонансному конденсаторі 330 пФ для підняття 44 мВ до 3–5 В, достатніх для ініціалізації BQ25570.

**Недоліки каскаду LTC3108 → BQ25570:**
- +2 компоненти на платі: трансформатор (великий, дорогий) + LTC3108
- Зниження загального ККД (два каскади vs один)
- Збільшення площі плати ~40%
- Складніша збірка та налагодження

### 1.3. Архітектурний Пів'от

**Ключове відкриття:** Повноцінний EBFC на основі ферментів GOx/Laccase, іммобілізованих на гіроїдній поверхні Ti-6Al-4V, генерує **понад 500 мВ** — значно більше, ніж 44 мВ від простого ксилемного потокового потенціалу на металевих електродах без ферментів.

500 мВ > 330 мВ (поріг Cold-Start BQ25570) → **LTC3108 більше не потрібен!**

```
Поточна архітектура (Post-Pivot):

Tree EBFC (>500mV)
      │
      ▼  VIN_DC (>500mV, типово 500–800mV)
┌──────────────────────────────────────────────┐
│  BQ25570 (Power Management IC)               │
│  CJMCU-25570 breakout module                 │
│  - Cold Start: OK (330mV порог перекрито)    │
│  - MPPT: VOC sampling / 16s                  │
│  - Boost Charger → VSTOR (до 5.5V)          │
│  - Buck Converter → VOUT (3.3V стабілізовано)│
│  - VBAT_OK → GPIO STM32 (дозвіл пробудження)│
└───────────────────┬──────────────────────────┘
                    │
                    ▼  VSTOR (накопичення)
           [ Supercapacitor 0.47F / 5.5V ]
                    │
                    ▼  VOUT (3.3V, до 100 mA)
           [ STM32WLE5JC + SX1262 LoRa ]
```

**Результат пів'оту:**
- Видалено LTC3108, трансформатор 1:100 та резонансний конденсатор 330 пФ
- Зменшення BOM на 3 компоненти
- Зменшення площі плати ~40%
- Підвищення загального ККД (один каскад замість двох)
- Спрощення налагодження

## 🔌 2. Опис Пінів BQ25570

### VSTOR

**Призначення:** Підключення до суперконденсатора (накопичувач енергії).

```
VSTOR ── [0.47F / 5.5V Supercapacitor] ── GND
```

- **Діапазон:** 0V (повний розряд) до 5.5V (максимум суперконденсатора)
- **Логіка:** Boost-конвертер "перекачує" заряд з EBFC до VSTOR, поступово піднімаючи напругу від 0V
- **Захист:** VBAT_OV (Overvoltage) = 5.5V — при досягненні мікросхема зупиняє заряд
- **Firmware relevance:** `vcap_voltage` в 21-байтному пакеті (bytes 5–6) = напруга на VSTOR, виміряна ADC STM32

### VOUT

**Призначення:** Стабілізований вихід для живлення мікроконтролера та LoRa-трансивера.

```
VSTOR ──[Internal Buck]──▶ VOUT (3.3V) ──▶ STM32WLE5JC VDD
                                       ──▶ SX1262 LoRa Radio
```

- **Значення:** 3.3V (програмується резисторами ROUT1/ROUT2)
- **Максимальний струм:** 100 mA (постійний)
- **Пікове навантаження:** LoRa TX +22 dBm потребує до 118 mA → необхідний Buffer Cap (розділ 5)
- **Увімкнення:** Тільки коли VSTOR > VBAT_OK threshold (3.4V) → VBAT_OK = HIGH
- **Quiescent Current Buck:** входить до загального IQ = 488 nA (в режимі очікування)

### VBAT_OK

**Призначення:** Логічний вихід-дозволювач для пробудження STM32WLE5JC.

```
BQ25570 VBAT_OK ──▶ STM32 GPIO (EXTI або wake-up pin)
```

**Логіка спрацьовування (гістерезис):**

| Умова | Напруга VSTOR | VBAT_OK | Стан MCU |
|---|---|---|---|
| Іоністор заряджається | < 3.4V | LOW (0V) | STOP2 (глибокий сон) |
| Іоністор досяг порогу | ≥ 3.4V | HIGH (3.3V) | Дозвіл пробудження |
| Іоністор розряджається | > 3.32V | HIGH | MCU продовжує роботу |
| Іоністор критично сів | < 3.32V (~97% від 3.4V) | LOW → HIGH (гіст.) | MCU засинає (STOP2) |

**Гістерезис** (~3%, вбудований в BQ25570) запобігає швидкому перемиканню при граничній напрузі ("дрижання" / chatter).

**У Firmware:** STM32 виходить з STOP2 після апаратного переривання на піні VBAT_OK (через HAL_PWR_EnableWakeUpPin або EXTI rising edge).

## 🏗️ 3. Внутрішня Архітектура BQ25570

BQ25570 об'єднує три незалежні підсистеми в одному чіпі:

### 3.1. Cold Start Circuit (Система Холодного Старту)

**Умова активації:** VIN > 330 мВ та IIN > 15 мкА (наш EBFC: VIN ≈ 500–800 мВ → ✅)

- Спрощена "накачувальна помпа" (charge pump) з низьким пороговим струмом
- Заряджає VSTOR від 0V до ~1.8V (без MPPT, просто "накачує")
- При VSTOR ≥ 1.8V — вмикається основний Boost-конвертер (MPPT)

**Для нашої системи:** після місяців зберігання на складі або після повного розряду, достатньо буде навіть мінімального зимового EBFC-струму для запуску Cold Start.

### 3.2. Boost Charger з MPPT (Підвищуючий Зарядний Конвертер)

**Принцип роботи MPPT (Maximum Power Point Tracking):**
- Кожні **16 секунд** BQ25570 на **256 мс** від'єднує навантаження (EBFC "дихає")
- Вимірює VOC (Open Circuit Voltage) — напругу без навантаження
- Встановлює робочу точку: V_MPP = ROC_fraction × VOC
- Для нашого 50% налаштування: V_MPP = 0.5 × VOC

**Чому важливий MPPT для EBFC:** EBFC має нелінійну характеристику P-V (потужність-напруга). Без MPPT система може "пристрілятися" в неоптимальній точці і видавати в 2–3 рази менше потужності.

### 3.3. Buck Converter (Понижуючий Стабілізатор)

- **Вхід:** VSTOR (0–5.5V, нестабільна)
- **Вихід:** VOUT = 3.3V (стабілізована, до 100 mA)
- **Quiescent Current:** 488 нА (в режимі без навантаження — критично для бюджету)
- **Увімкнення:** Тільки при VSTOR > VBAT_OK threshold

## 🧮 4. Розрахунок Програмуючих Резисторів

BQ25570 програмується виключно апаратно через SMD-резистори (допуск **1%**, рекомендований розмір **0402**).

**Базова формула (V_REF = 1.21V, внутрішній опорний):**

```
V_threshold = V_REF × (1 + R_upper / R_lower)
```

### А. MPPT Sampling Fraction

**Ціль:** 65% від VOC (рекомендована початкова точка для EBFC на базі GOx/Laccase, див. BLOCKER-2)

> **Попередня конфігурація (50%)** наведена нижче для порівняння. Для лабораторних тестів починати з 65%.

```
MPPT_fraction = ROC2 / (ROC1 + ROC2)
```

**Конфігурація 65% (рекомендована для EBFC):**

| Компонент | Значення | Допуск | Корпус |
|---|---|---|---|
| ROC1 | **5.36 MΩ** | 1% | 0402 |
| ROC2 | **10.0 MΩ** | 1% | 0402 |
| MPPT fraction (actual) | **65.1%** | — | — |

**Конфігурація 50% (поточна, для порівняння/TEG):**

| Компонент | Значення | Допуск | Корпус |
|---|---|---|---|
| ROC1 | **10.0 MΩ** | 1% | 0402 |
| ROC2 | **10.0 MΩ** | 1% | 0402 |
| MPPT fraction (actual) | **50.0%** | — | — |

> ⚠️ **BLOCKER-2:** Фінальний коефіцієнт потребує емпіричного визначення з P-V кривою EBFC. Почати з 65%, при масо-транспортних обмеженнях знизити до 60%.

### Б. Overvoltage Protection

**Ціль:** VBAT_OV = **5.5V** (максимальна напруга суперконденсатора 0.47F/5.5V)

```
VBAT_OV = 1.21 × (1 + ROV1/ROV2) = 5.5V
1 + ROV1/ROV2 = 5.5 / 1.21 = 4.545
ROV1/ROV2 = 3.545

Вибираємо ROV2 = 4.75 MΩ (E96):
ROV1 = 3.545 × 4.75 = 16.84 MΩ → 16.9 MΩ (E96)

Перевірка: 1.21 × (1 + 16.9/4.75) = 1.21 × 4.558 = 5.515V ≈ 5.5V ✓
```

| Компонент | Значення | Допуск | Корпус |
|---|---|---|---|
| ROV1 | **16.9 MΩ** | 1% | 0402 |
| ROV2 | **4.75 MΩ** | 1% | 0402 |
| VBAT_OV (розрах.) | **5.52V** | ±55 мВ (1%) | — |

> ⚠️ **BLOCKER-1:** Ці значення потребують фізичної верифікації на CJMCU-25570 модулі. Дефолтні резистори модуля налаштовані на Li-Po (~4.2V OV), що не підходить для нашого 5.5V суперконденсатора!

### В. Undervoltage Protection

**Ціль:** VBAT_UV = **3.0V** (критичний розряд — нижче цього BQ25570 вимикає VOUT та VBAT_OK)

```
VBAT_UV = 1.21 × (1 + RUV1/RUV2) = 3.0V
1 + RUV1/RUV2 = 3.0 / 1.21 = 2.479
RUV1/RUV2 = 1.479

Вибираємо RUV2 = 4.75 MΩ (E96):
RUV1 = 1.479 × 4.75 = 7.02 MΩ → 7.15 MΩ (E96)
```

## 🛡️ 6. Апаратний Хак: Buffer Cap для Піку LoRa TX

**Проблема:** Buck-конвертер BQ25570 видає максимум **100 mA** постійного струму. Але під час відправки пакету LoRa на максимальній потужності (+22 dBm) трансивер SX1262 споживає до **118 mA** (пік ~100 мс). Різниця 18 мА може спричинити просадку напруги (Brownout) та скидання STM32.

**Рішення (Zero-Trust Hardware):** Локальний керамічний конденсатор із низьким ESR безпосередньо на лінії VOUT:

```
VOUT (3.3V) ──┬── [STM32WLE5JC 3V3 pin]
              │
             [100µF / 6.3V MLCC X5R, low-ESR]
              │
             GND
```

- **Ємність:** 100 µF, 6.3V (безпечний запас над 3.3V)
- **Тип:** ✅ **MLCC X5R або X7R** (корпус 1206 або 1210) — **НЕ танталовий**
- **Розміщення:** Якомога ближче до пінів живлення STM32 на PCB

> ⚠️ **Критичне зауваження (Legacy notes):** Рання специфікація вказувала "100µF / 6.3V Tantalum, low-ESR". Танталові конденсатори (особливо полімерні) мають **катастрофічно високий струм витоку (Leakage Current)** — від 1 до 10 мкА для ємності 100 мкФ. Це подвоїть або потроїть фонове споживання системи (E_sleep ≈ 1.5 мкА), фактично знищивши весь енергетичний бюджет, розрахований у секції 8.
>
> **MLCC (Ceramic Multilayer)** мають виток на рівні **десятків наноампер** (в 100-1000 разів менше) і ESR нижчий за тантал. Єдиний недолік MLCC — ємність падає при прикладеній DC напрузі (DC bias derating для X5R: ~20% при 3.3V/6.3V), але навіть 80 мкФ ефективної ємності більш ніж достатньо для покриття 100 мс LoRa TX піку.

**Фізика:** Під час 100 мс LoRa TX-пострілу 18 мА надлишкового струму надходить безпосередньо з конденсатора (Δt = 100 мс, ΔQ = 18 мА × 100 мс = 1.8 мКл). Напруга просяде лише на: ΔV = ΔQ/C = 1.8 мКл / 100 µФ = 18 мВ — незначно (STM32 витримує 1.7–3.6V). Після сну BQ25570 спокійно дозаряджає конденсатор.

## 🔋 7. Логіка VBAT_OK: Коли Мікроконтролер Прокидається?

Сигнал `VBAT_OK` від BQ25570 — це апаратний "дозволювач" для STM32. Він реалізує принцип "Нульового Лагу": MCU не витрачає жодної енергії на опитування напруги — BQ25570 сам повідомляє коли готовий.

```
Часовий графік (типовий цикл):

0 год      0.5 год     0.75 год    1+ год
│          │           │           │
│ Холодний ▼ VSTOR     ▼ VBAT_OK   ▼ LoRa TX
│  старт   зростає     стає HIGH   цикл починається
│ (EBFC)   (0→3.4V)   (MCU BOOT)   (через 15-30 хв першого заряду)
│
└── VBAT_OK ──LOW (MCU = STOP2) ──────────────▶ HIGH ──── MCU активний
                                                       (VSTOR ≥ 3.4V)
```

**Поведінка в реальних умовах:**
- **Після монтажу (свіжий супер-кап, 0V):** BQ25570 Cold-Start → VSTOR повільно зростає → через 15–30 хвилин досягає 3.4V → VBAT_OK = HIGH → STM32 завантажується вперше
- **Нічна робота (низький EBFC-струм):** VSTOR може повільно падати → при VSTOR < 3.31V → VBAT_OK = LOW → STM32 переходить у STOP2 → зберігає стан у RTC Backup registers
- **Відновлення зранку:** Сонце прогріває ліс → EBFC-струм зростає → VSTOR знову перевищує 3.4V → VBAT_OK = HIGH → STM32 відновлює роботу

**Критичний пороговий ланцюжок:**
```
EBFC (>500mV) → BQ25570 Boost → VSTOR ≥ 3.4V → VBAT_OK HIGH
                                              → Buck ON → VOUT = 3.3V
                                              → STM32 GPIO interrupt → Wakeup from STOP2
                                              → Firmware Phase 1: SENSE
```

## ⚡ 9. Розрахунок Енергетичного Балансу

### 9.1 Генерація Енергії

Потужність генерації EBFC та загальна акумульована енергія за одну годину:

```
P_gen = 15 × 10⁻⁶ Вт  (типовий EBFC у виробничому середовищі)
t     = 3600 с         (1 година)

E_gen = P_gen × t = 15 × 10⁻⁶ × 3600 = 0.054 Дж = 54 мДж
```

### 9.2 Фонове Споживання та Витоки

Струм сну, фонова потужність та втрати енергії в режимі очікування за годину:

```
I_sleep = I_STM32_STOP2 + I_BQ25570_quiescent
        = 1.07 мкА      + 0.488 мкА ≈ 1.558 мкА  (≈ 1.5 мкА округлено)

V       = 3.3 В

P_sleep = I_sleep × V = 1.5 × 10⁻⁶ А × 3.3 В = 4.95 мкВт

E_sleep = P_sleep × t = 4.95 × 10⁻⁶ Вт × 3600 с = 0.01782 Дж = 17.82 мДж
```

**Чистий енергетичний приріст системи за годину:**

```
E_net = E_gen − E_sleep = 54 мДж − 17.82 мДж = 36.18 мДж
```

### 9.3 Вартість Активного Мікроциклу

Витрати енергії на одне пробудження: обчислення (TinyML + mruby) та радіопередача (LoRa TX):

> ⚠️ **Виправлено (DOC.16):** Попередня версія використовувала занижені TX-параметри (15 мА / 50 мс).
> Реальний струм SX1262 при +22 dBm = **118 мА** (datasheet, §6 цього документа). У розрахунках використовується
> округлене значення **120 мА** для консервативної оцінки (узгоджено з `02_01_Hardware_Architecture_and_BOM`).

```
E_tinyml = I_tinyml × V × t_tinyml = 12 мА × 3.3 В × 0.2 с  = 7.92 мДж
E_mruby  = I_mruby  × V × t_mruby  = 8 мА  × 3.3 В × 0.15 с = 3.96 мДж
E_tx     = I_tx     × V × t_tx     = 120 мА × 3.3 В × 0.1 с  = 39.6 мДж
```

| Компонент | Струм | Напруга | Час | Енергія |
|---|---|---|---|---|
| TinyML Inference | 12 мА | 3.3 В | 0.2 с | **7.92 мДж** |
| mruby Lorenz (250 it.) | 8 мА | 3.3 В | 0.15 с | **3.96 мДж** |
| LoRa TX (+22 dBm) | 120 мА | 3.3 В | 0.1 с | **39.6 мДж** |
| **Разом (E_cycle)** | | | | **~51 мДж** |

### 9.4 Розрахунок Інтервалу Передачі

Максимальна теоретична кількість повідомлень на годину та мінімальний інтервал між ними:

```
N_msg      = E_net / E_cycle = 36.18 мДж / 51 мДж ≈ 0.71 повідомлень/год   (мінімум EBFC)
N_msg_max  = (72 − 17.82) / 51 = 54.18 / 51   ≈ 1.06 повідомлень/год   (оптимум EBFC)

T_interval_min  = 60 / 1.06 ≈ 57 хвилин  (при оптимальній генерації 72 мДж/год)
T_interval_max  = 60 / 0.71 ≈ 85 хвилин  (при мінімальній генерації 54 мДж/год)
```

> **Висновок:** При оптимальній генерації EBFC (72 мДж/год, літо/активний фотосинтез) система здатна надсилати **~1 пакет на годину** (кожні ~57 хв) — на межі енергетичного балансу. При мінімальній генерації (54 мДж/год) інтервал зростає до ~85 хв. Це узгоджується з архітектурним рішенням про цикл пробудження кожну годину (фаза STOP2 з RTC Wake-Up) та підтверджує, що LoRa TX (+22 dBm, 120 мА) є домінуючим споживачем (~78% E_cycle).

> ⚠️ **Примітка про сезонність:** `P_gen = 15 мкВт` — типовий рівень для EBFC при оптимальних умовах (влітку, активний фотосинтез). У зимовий період або в умовах зниженої метаболічної активності `P_gen` може бути в 3-5 разів нижчим. У таких умовах система автоматично збільшує інтервал пробудження (адаптивний цикл Soldier) або переходить у режим "мовчання = здоров'я" (ARCH.8).

## 🧪 10. Прототипна Зборка на Breadboard

### Золоте Правило: Спільна Земля

**Перед будь-яким підключенням:** усі `-` (GND) від усіх плат, батарейок та іоністора — в єдину **синю лінію** (шину) вздовж краю Breadboard. Без спільної землі логічні рівні перетворяться на хаос.

### Як Працює Breadboard (Внутрішній API)

Під пластиком Breadboard ховаються металеві рейки-кліпси:
- **Центральна частина:** горизонтальні рядки по 5 отворів (A-B-C-D-E). Всі 5 отворів одного рядка фізично з'єднані однією металевою пластиною. Вставити дріт у `10A` і `10C` = з'єднати їх напряму.
- **Крайні лінії (червона/синя):** вертикальні шини, з'єднані по всій довжині. Синя = GND, червона = VCC.

> `variable = 44_mV` ≡ увіткнути перемичку з рядку з 44 мВ у рядок з піном VIN мікросхеми.

---

### Острів 1: Симулятор "Дерева" (Дільник Напруги 1.5V → 44 мВ)

**Мета:** Імітувати ксилемний потоковий потенціал EBFC (44 мВ) з батарейки AA (1.5V) для лабораторних тестів без живого дерева.

**Компоненти:**
- Батарейка AA 1.5V з відсіком та тумблером
- Резистор **R1 = 3.3 кОм** (3300 Ом)
- Резистор **R2 = 100 Ом**

**Формула дільника напруги:**

$$V_{out} = V_{in} 	imes rac{R_2}{R_1 + R_2} = 1.5	ext{ В} 	imes rac{100	ext{ Ом}}{3300	ext{ Ом} + 100	ext{ Ом}} pprox \mathbf{0.044	ext{ В} = 44	ext{ мВ}}$$

### Острів 2: Каскад Збору

> **Контекст:** LTC3108 використовується в лабораторному прототипі для демонстрації роботи від наддалеких напруг (44 мВ). У виробничій архітектурі (пост-пів'від, TRL 5+) LTC3108 **видалено** — EBFC на GOx/Laccase генерує >500 мВ, що вище порогу Cold-Start BQ25570 (330 мВ). Деталі пів'від — розділ 1.3 цього документа.

**Компоненти:**
- Плата-перехідник з **LTC3108** (Linear Technology)
- Трансформатор **Coilcraft LPR6235-752SMRC** (1:100 — первинна:вторинна)
- Керамічний конденсатор **330 пФ** (резонансний — задає частоту осцилятора)
- Конденсатор **1 мкФ** (між VAUX та GND)
- Конденсатор **2.2 мкФ** (між VLDO та GND)

#### Анатомія Осцилятора (Фізика)

LTC3108 + трансформатор = гойдалка-резонатор:
1. 44 мВ → первинна котушка трансформатора
2. Трансформатор підсилює через індукцію → повертає поштовх у мікросхему
3. Мікросхема знову штовхає котушку (сильніше) → резонанс
4. Цей цикл × тисячі разів/секунду → напруга зростає з 44 мВ до ~2-3 В
5. Конденсатор 330 пФ = "маятник" що задає безпечну частоту розгойдування

### Острів 3: Менеджер та Резервуар

**Компоненти:**
- Модуль **CJMCU-25570** (BQ25570 breakout, червона плата)
- Іоністор (supercapacitor) **0.47 Ф / 5.5V** (циліндричний)

> ⚠️ **Полярність іоністора:** Довга ніжка = **Плюс (+)**. Коротка ніжка або ніжка зі світлою смужкою на корпусі = **Мінус (−)**. При переплутуванні полярності — іоністор може вибухнути.

**Зборка:**

```
LTC3108 VOUT ──── пін VIN_DC (BQ25570)      ← Вхід енергії від Острова 2
Синя лінія   ──── пін GND (BQ25570)          ← Земля
Іоністор (+) ──── пін VBAT (BQ25570)         ← Накопичувач (резервуар)
Іоністор (-) ──── Синя лінія GND             ← Мінус іоністора = земля

BQ25570 VOUT ──── перемичка → Острів 4       ← 3.3V для мікроконтролера
```

**Що відбувається фізично:**
- BQ25570 бере мікрокраплі енергії від LTC3108 і по краплях заливає їх в іоністор
- Іоністор повільно заряджається (0 → 3.4V → 5.5V)
- Коли VSTOR ≥ 3.4V → BQ25570 відкриває Buck-конвертер → VOUT = 3.3V

---

### Острів 4: Мозок та Радіо

**Зборка:**

```
BQ25570 VOUT ──── пін 3V3 (LoRa-E5 mini)    ← Живлення від "дерева"
Синя лінія   ──── пін GND (LoRa-E5)          ← Земля
```

> Розмістіть плату LoRa-E5 на краю Breadboard для зручного підключення Type-C (прошивка) та ST-LINK (SWD debug).

---

### Тестовий Запуск (Перший Холодний Старт)

**Послідовність:**

1. Зберіть усі острови. Перевірте всі GND-з'єднання в синій лінії
2. Підключіть мультиметр (щупи на ніжки іоністора). Показання = **0 В**
3. Клацніть тумблер батарейки → **ON**
4. На дисплеї мультиметра ви побачите:
   ```
   0.1 В ... 0.3 В ... 0.8 В ... 1.5 В ... 2.2 В ... 3.0 В ... 3.4 В
   ```
   Іоністор повільно, мілівольт за мілівольтом, накопичує енергію
5. Час до першого запуску: **15-30 хвилин** (перший холодний старт з нуля)
6. Коли VSTOR ≥ 3.4V → BQ25570 подасть 3.3V на LoRa-E5 → **блимне світлодіод**

> **Ваша система ожила від 44 мілівольтів.** Енергії, якої б не вистачило навіть на один піксель дисплея MacBook.
