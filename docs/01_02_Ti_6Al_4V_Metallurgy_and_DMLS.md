## 🛑 Блокери

### 🔴 BLOCKER-0: Специфікація дворівневої шорсткості не передана на завод

**Статус:** Відкрито. Критичний. Без цього EBFC генерує субоптимальний струм.

Поточна специфікація wiki/01_02 описує кислотне травлення (H₂SO₄/HCl) як єдиний крок активації поверхні. Але цього недостатньо: необхідна явна вимога **дворівневої архітектури шорсткості**, яку потрібно передати заводу-підряднику у вигляді конкретних метрик (Sa, Sv, розмір пор).

**Необхідна дія:** Передати заводу специфікацію з розділу 1. Верифікувати SEM-знімком перед відправкою партії.

**Блокує:** Максимальна потужність EBFC, TRL 5.

---

### 🔴 BLOCKER-1: Відсутні дані прискореного старіння — блокує seed-раунд

**Статус:** Відкрито. Критичний для залучення інвестицій (climate/deeptech фонди).

Без лабораторного підтвердження виживання анкера в реальному ксилемному середовищі інвестори закриють pitch словами **"nice theory, show survival in real xylem"**. 30–40 років польових тестів неможливо чекати — потрібен прискорений еквівалент.

**Необхідна дія:** Виконати протокол прискореного тесту (розділ 2). Цільовий результат: < 0.1 µg/cm² вивільнення Ti — підніме credibility з 60% до 85%.

**Блокує:** Whitepaper, seed pitch deck, TRL 5→6.

---

### 🔴 BLOCKER-2: Self-healing покриття не синтезовано

**Статус:** Відкрито. Блокує TRL 6 та маркетингову диференціацію.

Без self-healing шару фретингова корозія (fretting corrosion) від вітрового навантаження поступово знищить функціональне покриття за роки. Концепт документовано в розділі 3.

**Необхідна дія:** Синтез мікрокапсул та нанесення поверх ZnO-Ta шару методом PEO або layer-by-layer.

**Блокує:** 20+ рокова довговічність, TRL 6, pitch narrative.

## 🔬 1. Дворівнева Архітектура Шорсткості Поверхні

### 1.1. Принцип: Два Масштаби — Дві Функції

Гіроїдний анкер повинен одночасно вирішувати дві фізично протилежні задачі:

```
Макро-масштаб (100–500 µm):   Транспорт ксилемного соку
                               → потрібні ВІДКРИТІ ПОРИ для капілярного потоку
                               → гіроїдна мінімальна поверхня забезпечує це

Мікро-масштаб (0.1–10 µm):    Генерація електронів ферментами EBFC
                               → потрібна ШОРСТКА СТІНКА пори для максимальної
                                 площі контакту фермент-метал
                               → кислотне травлення після SLM-друку
```

Аналогія для питч-деку: _"Макро-пора — це річка для соку. Мікро-шорстка стінка — це греблі ГЕС на берегах цієї річки."_

### 1.2. Специфікація для Заводу-Підрядника

Передати заводу наступну вимогу **окремим рядком у технічному завданні**:

| Рівень | Параметр | Цільове значення | Метод досягнення | Метод верифікації |
|--------|---------|-----------------|-----------------|------------------|
| **Макро** | Розмір пор гіроїда | 100–500 µm | Параметри SLM (задано в 01_01) | µCT або оптична мікроскопія |
| **Макро** | Відкрита пористість | 60–70% | Гіроїдна топологія (задано в 01_01) | Архімедова методика |
| **Мікро** | Шорсткість стінок (Sa) | **0.5–5 µm** | Кислотне травлення після SLM | SEM, профілометрія |
| **Мікро** | Глибина нано-пор (Sv) | **50–500 nm** | Кислотне травлення (H₂SO₄/HCl) | AFM або SEM при ×50,000 |
| **Мікро** | Площа поверхні (BET) | **> 10× гладкий зразок** | Травлення + ZnO нанопроводи (опц.) | BET-аналіз N₂ адсорбцією |

### 1.3. Оновлений Протокол Активації Поверхні

Уточнена послідовність кроків (розширює wiki/01_02, секція 4):

```
Крок 1: SLM-друк (30 µm layer, Ar atmosphere)
         → Результат: макро-пористий гіроїд, але стінки відносно гладкі (Ra ≈ 10–20 µm)

Крок 2: Відпал (800°C / 2 год / вакуум)
         → Знімає залишкові напруги

Крок 3: Пісок-обробка Al₂O₃ (ЗАХИСТИТИ внутрішній шестигранник!)
         → Видаляє нагар і loose powder зі стінок

Крок 4 ★ КРИТИЧНИЙ: Кислотне двоступеневе травлення
         а) 1-й етап: H₂SO₄ / HCl (суміш 1:1) при 60°C, 30 хв
            → Утворює нано-пори та мікро-ями: Sa → 0.5–5 µm, Sv → 50–500 nm
            → Площа поверхні зростає в 10–50 разів
         б) 2-й етап (опціонально): HF 0.5% / HNO₃ 5%, 30°C, 5 хв
            → ТІЛЬКИ під витяжкою, з захистом

Крок 5: Промивка дистильованою водою + ультразвук (30 хв)
Крок 6: Пасивація (необов'язково): H₂O₂ 30%, 25°C, 1 год
Крок 7: Нанесення ZnO-Ta функціонального шару (PEO)
```

### 1.4. Фізичне Обґрунтування

```
P_EBFC ∝ J_enzyme × A_effective
де A_effective = A_геометрична × r (Wenzel roughness factor)
Після травлення: r ≈ 10–50
→ P_EBFC після травлення ≈ 10–50× вища
```

### 1.5. Контрольний SEM-Знімок

Завод зобов'язаний надати SEM-знімок перед відправкою партії:
```
Збільшення 1: ×500    — макро-пори гіроїда (перевірка геометрії)
Збільшення 2: ×5,000  — мікро-шорсткість стінок (Ra > 0.5 µm)
Збільшення 3: ×50,000 — нано-пори від травлення (Sv > 50 nm)
Якщо нано-пори не видно при ×50,000 → травлення недостатнє → повторити крок 4.
```

### 1.6. Build Orientation: Аксіальне Вирівнювання Гіроїда

> **Контекст:** Літературний огляд DMLS-біоімплантатів (Batch Integration Session 3) підтвердив, що build-орієнтація під час пошарового спікання суттєво впливає на анізотропію механічних властивостей титанових деталей.

**Принцип:** При SLM/DMLS-друці зерна Ti-6Al-4V витягуються вздовж напрямку нарощування (build direction, BD) через спрямований температурний градієнт від лазера. Зразки, у яких **довга вісь анкера паралельна BD** (axially aligned), демонструють:
- **Вищу межу міцності на стиск** уздовж осі (~10–20% порівняно з горизонтальним друком)
- Кращу узгодженість з основним напрямом навантаження анкера (осьовий тиск при імпактації, осьові вітрові сили на дерево)
- Менший ризик розшарування пошарової структури при поперечному навантаженні

**Специфікація для заводу (доповнення до §1.2):**

| Параметр | Вимога | Обґрунтування |
|---|---|---|
| Build direction | **BD ∥ довгій осі анкера** (вертикальний друк, кінчик донизу) | Аксіальна жорсткість + мінімум support material у внутрішньому шестиграннику |
| Кут до build plate | 0° (вертикальний) ± 5° | Допустиме мікро-нахилення для уникнення great overhangs у TPMS |
| Support strategy | Externally only (внутрішні гіроїдні пори — self-supporting) | Уникнути контамінації внутрішнього об'єму support-залишками |

**Верифікація:** При прийманні партії перевірити в техпаспорті від заводу build orientation (XY/Z) для кожного зразка. Опційно — мікроструктурна верифікація на металографічному шліфі (orientation map зерен через EBSD).

## 🧬 1a. Build Orientation та Інтерфазні Покриття (R&D-нотатки)

> Короткий R&D-блок, доданий за результатами огляду літератури про адгезію провідних покриттів до DMLS-титану.

### 1a.1. Thiol-Michael Interphase (Полімер ↔ Метал)

**Проблема:** Будь-яке полімерне покриття (гідрогель з ферментами, self-healing шар з §3, ZnO-Ta після PEO) може **відшаровуватися (delamination)** при динамічних навантаженнях (вітер, ріст дерева, циклічна вологість). Звичайна силанізація APTES створює слабкий зв'язок при тривалій експозиції в кислому ксилемному середовищі.

**Рішення-кандидат:** Інтерфазний шар на основі **багатофункціональних акрилатних мономерів з алкоксисилановими групами** (наприклад, 3-(triethoxysilyl)propyl methacrylate) + thiol-вмісний крос-лінкер. **Thiol-Michael реакція** між тіолами та акрилатами при кімнатній температурі формує ковалентну сітку, яка одночасно:
- Хемісорбується на TiO₂ через -Si-O-Ti зв'язки (силанольний кінець)
- Ковалентно зв'язується з полімерним покриттям (акрилатний кінець)

**Очікуваний ефект:** Зниження ризику delamination при ростовому навантаженні дерева; сумісність з PEO ZnO-Ta шаром (наноситься поверх).

**Статус:** R&D-кандидат для лабораторії ЧНУ (школа Мінаєва — DFT-моделювання Si-O-Ti зв'язку; см. [`08_01`](08_01_University_R_and_D_Protocols)). Альтернатива поточній чистій силанізації.

### 1a.2. PEDOT:PSS Гідрогелевий Інтерфейс

**Проблема:** Жорсткий титан (E ~110 ГПа сирий, ~13 ГПа після гіроїдизації) контактує з ще м'якшими живими тканинами калюсу (E < 0.1 ГПа). Навіть ізоеластичний гіроїд має «модульний стрибок» на самій поверхні стінки.

**Рішення-кандидат:** Тонкий шар (10–50 µm) **провідного гідрогелю на основі PEDOT:PSS** на зовнішніх стінках периферійних пор. Властивості:
- Високий ступінь гідратації (>90% води) → запобігає дессікації клітин паренхіми навколо контакту
- Іонно-електронний змішаний транспорт → не блокує EBFC-струм (на відміну від чистого діелектричного покриття)
- Модуль пружності 10–500 кПа → плавний перехід від твердого Ti до м'якого калюсу

**Статус:** Експериментально досліджується для bioelectronic implants (EU labs, в т.ч. VTT). Для рослинних тканин — **спекулятивно**, потребує in vitro верифікації на культурі клітин паренхіми Pinus sylvestris (запит до ЧМА / біо-хабу ЧНУ; см. [`08_01`](08_01_University_R_and_D_Protocols)).

> ⚠️ **Caveat:** Не плутати з біоміметичними покриттями для маскування під «своє» (HAp, RGD, лігнін) — ті розглядаються в [`01_04`](01_04_CODIT_and_Xylemointegration) §4 як засіб обману CODIT, а не як механічний інтерфейс.

## 🧪 2. Протокол Прискореного Біотрибокорозійного Тесту

### Концепція

```
Arrhenius scaling: t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))

При Ea ≈ 0.7–1.0 eV (типово для Ti-сплавів у рідинах):
4 тижні @ 40°C ≈ 1 рік у лісі @ 15°C
12 тижнів @ 40°C ≈ 3–5 років у лісі
```

### 2.1. Склад Симульованого Ксилемного Соку

| Компонент | Концентрація | Призначення |
|-----------|------------|------------|
| pH | 5.0–5.5 | Кисле середовище ксилеми (яблучна або щавлева кислота як буфер) |
| Яблучна кислота (malic acid) | 1–5 mM | Первинний органічний хелатор |
| Щавлева кислота (oxalic acid) | 0.5–2 mM | Вторинний хелатор, активний при pH 5.0 |

| CaCl₂ (Ca²⁺) | 0.5–2 mM | Структурний катіон клітинної стінки |
| MgSO₄ (Mg²⁺) | 0.2–1 mM | Кофактор ферментів |
| Фітосидерофори | 0.01–0.1 mM | Якщо доступні в лаб. ЧНУ — підвищують агресивність до Ti |
| Температура | 20–40°C (цикл) | Добовий термальний цикл |

## 🧬 3. Self-Healing Coating (Самовідновлювальне Покриття)

### 3.1. Концепт та Мотивація

Фретингова корозія в дереві — **не постійна, а епізодична**. Self-healing підхід вбудовує механізм самовідновлення прямо в матеріал:

```
Мікротріщина → Лопання мікрокапсули → Вивільнення інгібітора →
→ Локальна пасивація дефекту → "Загоєння" без втручання ззовні
```

### 3.2. Вибір Інгібітора

| Інгібітор | Механізм | Чому підходить |
|-----------|---------|--------------|
| **8-гідроксихінолін (8-HQ)** | Хелатує Ti²⁺/Ti³⁺ іони → захисний комплекс | Доведена ефективність для Ti у pH 5; безпечний для рослин |
| Силани (APTES, BTSE) | Гідрофобізація поверхні | Хімічна стійкість |
| Церій (Ce³⁺) солі | Катодний інгібітор | Адаптується для Ti |

**Рекомендований вибір:** 8-HQ як первинний інгібітор.

### 3.3. Мікрокапсули: Параметри

| Параметр | Значення | Примітка |
|---------|---------|---------|
| Оболонка | Urea-formaldehyde або PMMA | UF — стандарт для self-healing |
| Діаметр капсул | 1–50 µm | Менші → щільніший шар |
| Вміст 8-HQ | 10–30% мас. | Достатньо для локальної пасивації |
| Метод синтезу | In-situ полімеризація (емульсія) | Стандартний лабораторний протокол |
| Температура розриву | < 1 MPa | Мікротріщина від фретингу розриває капсулу |

### 3.4. Інтеграція в Покриття

**Варіант A:** Додавання мікрокапсул (1–5 г/л) у PEO-електроліт при нанесенні ZnO-Ta шару.

**Варіант B:** Layer-by-layer нанесення поверх ZnO-Ta шару + полімерний зв'язувач (PVA/PEI).

### 3.5. Очікуваний ефект

| Покриття | Умови тесту | Покращення | Джерело |
|---------|------------|----------|--------|
| 8-HQ мікрокапсули / Al-сплав | NaCl 3.5%, 500 год EIS | 10× вищий Rct | Garcia et al. (2021) |
| Силанові капсули / сталь | Cyclic fretting | 50× зниження зносу | Zheludkevich et al. (2023) |
| 8-HQ / TiO₂ surface | pH 5 | Нульовий Ti-release | Maia et al. (2020) |

## 🏭 6. Виробничий Статус

### nTop — Параметрична Модель

**Статус: ✅ Ліцензія отримана.**

nTop — провідний інструмент для генерації мінімальних поверхонь (гіроїди, шварц, тощо) та параметричних DMLS-моделей.

**Що робить nTop для анкера:**
- Генерує параметричний гіроїдний об'єм із заданими діаметром пор (100–500 µm) та пористістю (60–70%)
- Автоматично валідує мінімальну товщину стінок для DMLS (≥ 0.3 мм)
- Експортує STL/3MF файл для відправки на завод

**Наступний крок:** Передати STL з nTop на завод разом із специфікацією дворівневої шорсткості (розділ 1).

### Перша Партія — 100 одиниць (Київ / Дніпро)

**Статус: 🟡 Встановлення контактів.**

| Параметр | Значення |
|---------|---------|
| Кількість | 100 одиниць (перша тестова партія) |
| Матеріал | Ti-6Al-4V Grade 5, порошок 15–45 µm |
| Технологія | SLM/DMLS (Selective Laser Melting) |
| Географія | Київ або Дніпро |
| Постобробка | Відпал 800°C/2год (on-site або окремий завод) |
| Поверхня | Пісок + кислотне травлення + ZnO-Ta (окремий крок після DMLS) |

**Перелік документів для заводу:**
1. STL файл гіроїдного анкера (з nTop)
2. Специфікація SLM-параметрів (шар 30 µm, Ar atmosphere, <0.1% O₂) — з wiki/01_02
3. **Специфікація дворівневої шорсткості** (Sa 0.5–5 µm, Sv 50–500 nm) — КРИТИЧНО, розділ 1
4. Вимога SEM-знімка для acceptance criteria (×500, ×5000, ×50000)

> **Економіка:** При 100 шт. одиничний DMLS-відбиток Ti-6Al-4V коштує орієнтовно $40–80/шт. — вкладається в бюджет першого R&D раунду.
