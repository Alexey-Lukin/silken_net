### Протокол «Xylem-Sim» — Прискорений Тест (Деталізація)

> Доповнення до протоколу «Long-Term Integrity» (Школа Гусака). Конкретні параметри тестового стенду.

**Мета:** Довести, що Ti-6Al-4V не виділяє токсичних іонів у ксилемний сік та що провідність анкера не падає через окислення за 4-річний еквівалент (1 місяць лабораторного тесту).

#### Штучний аналог ксилемного соку (Pinus sylvestris, Черкаський бір)

| Компонент | Значення | Примітки |
|-----------|---------|---------|
| pH | 4.5–5.5 | Кислотне середовище ксилеми сосни |
| Яблучна кислота | 1–5 мМ | Первинний хелатор |
| Щавлева кислота | 0.5–2 мМ | Вторинний хелатор |
| K⁺ (KNO₃) | 2–5 мМ | Домінантний катіон ксилеми |
| Ca²⁺ (CaCl₂) | 0.5–2 мМ | Структурний катіон |
| Mg²⁺ (MgSO₄) | 0.2–1 мМ | Кофактор ферментів |
| Базова вода | Деіонізована | Без мінеральних контамінантів |

> **Точний склад** (сезонні варіації, регіональна специфіка) надають біоекологи ЧНУ (Спрягайло / Гаврилюк) на основі 10-річних вимірювань у Черкаському борі.

#### Електрохімічне прискорення (Arrhenius + струм)

```
1 місяць @ 40°C + електрохімічна стимуляція ≈ 4 роки польового тесту

Arrhenius scaling: t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))
T_field = 293K (20°C), T_lab = 313K (40°C), Ea ≈ 0.7–1.0 eV
```

Двоступеневе прискорення:
1. **Підвищена температура** (40°C): прискорює дифузійні процеси
2. **Слабкий електролітичний струм** (~10 µA/cm²): стимулює анодне розчинення та формування біоплівки, не пошкоджуючи структуру

#### Цільові показники (Investor-Grade Claims)

| Показник | Ціль | Метод вимірювання |
|---------|------|--------------------|
| Іони Ti у розчині | < 0.1 µg/cm² | ICP-MS |
| Іони Al у розчині | < 0.05 µg/cm² | ICP-MS |
| Іони V у розчині | < 0.02 µg/cm² (токсичний!) | ICP-MS |
| Провідність поверхні | деградація < 20% | EIS (імпедансна спектроскопія) |
| Морфологія поверхні | відсутність корозійних ямок > 10 µm | SEM |

#### Академічний вихід

Короткий науковий висновок, підписаний директором лабораторії ЧНУ:
> _"Ti-6Al-4V gyroid anchor demonstrates < 0.1 µg/cm² ion release after 4-year accelerated aging test in synthetic xylem sap of Pinus sylvestris (Cherkasy Pine Forest)"_

Цей документ — головний козир для:
- Сертифікаційних органів (ДСТУ, ISO)
- Кліматичних інвесторів (seed-раунд)
- Грантових заявок (Giveth, Gitcoin, МОН)
