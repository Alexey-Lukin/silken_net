### nTop — Параметрична Модель

**Статус: ✅ Ліцензія отримана.**

nTop (раніше nTopology) — провідний інструмент для генерації мінімальних поверхонь (гіроїди, шварц, тощо) та параметричних DMLS-моделей. Ліцензія nTop отримана та активована.

**Що робить nTop для анкера:**
- Генерує параметричний гіроїдний об'єм із заданими діаметром пор (100–500 µm) та пористістю (60–70%)
- Автоматично валідує мінімальну товщину стінок для DMLS (≥ 0.3 мм)
- Експортує STL/3MF файл для відправки на завод

**Наступний крок:** Передати STL з nTop на завод разом із специфікацією дворівневої шорсткості (розділ 1 вище).

---

### Перша Партія — 100 одиниць (Київ / Дніпро)

**Статус: 🟡 Встановлення контактів.**

Планується замовлення тестової партії у **100 одиниць** у DMLS-виробників в Україні. Опт (100 шт.) суттєво знижує ціну відносно одиничного виробництва.

| Параметр | Значення |
|---------|---------|
| Кількість | 100 одиниць (перша тестова партія) |
| Матеріал | Ti-6Al-4V Grade 5, порошок 15–45 µm |
| Технологія | SLM/DMLS (Selective Laser Melting) |
| Географія | Київ або Дніпро (встановлення контакту) |
| Постобробка | Відпал 800°C/2год (може бути on-site або окремий завод) |
| Обробка поверхні | Пісок + кислотне травлення + ZnO-Ta (окремий крок після DMLS) |

**Перелік документів для заводу:**
1. STL файл гіроїдного анкера (з nTop)
2. Специфікація SLM-параметрів (шар 30 µm, Ar atmosphere, <0.1% O₂) — з wiki/01_02
3. **Специфікація дворівневої шорсткості** (Sa 0.5–5 µm, Sv 50–500 nm) — КРИТИЧНО, розділ 1 цього документа
4. Вимога SEM-знімка для acceptance criteria (×500, ×5000, ×50000)
5. BOM поверхневої обробки для постобробки (або завод тільки DMLS + відпал, решта — окремо)

> **Економіка:** При 100 шт. одиничний DMLS-відбиток Ti-6Al-4V коштує орієнтовно $40–80/шт. залежно від об'єму та складності постобробки. Разом з ліцензійним відрахуванням nTop — це вкладається в бюджет для першого R&D раунду.
