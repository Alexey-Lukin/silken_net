# 02_01: Апаратна Архітектура та BOM — Капсула Солдата

---

## 🎯 Мета

Зафіксувати апаратну архітектуру (PCBA), логіку живлення та Bill of Materials (BOM) для герметичної капсули "Солдата". Капсула збирає енергію з коаксіального гіроїдного анкера (EBFC), зберігає її в іоністорі 0.47 F, аналізує звук TinyML, обчислює атрактор Лоренца (mruby) та передає 21-байтові зашифровані пакети через LoRa mesh 868 МГц.

---

## ✅ Статус

- **Поточний TRL:** TRL 6 — Апаратна архітектура заморожена, BOM синхронізовано, ціни підтверджено локальними DMLS-виробниками (→ `07_02_Unit_Economics_and_BOM`).
- **Ключовий Півот (v2):** Каскад LTC3108 та трансформатор 1:100 **повністю видалено**. EBFC генерує >500 мВ — вище порогу "холодного старту" BQ25570 (330 мВ). Скорочення BOM: −2 компоненти, −40% площі плати, +η загального ланцюга живлення. Перехід на коаксіальну **«Матрьошку»** (GOx анод + Laccase катод, вбудовані в гіроїдний анкер).
- **Антенна Підсистема (v2):** Відмова від зовнішніх U.FL-кабелів та 4 голок-електродів. Прийнято рішення: керамічна SMD-антена 868 МГц + PEEK-радом (детально в розділі 5).
- **Повна вартість вузла:** ~$32–$35 / шт (при 10k+), з урахуванням анкера + PEEK + герметизації. Детально → `07_02_Unit_Economics_and_BOM`.

## 📡 5. RF & Antenna Subsystem — Zero-Touch RF Architecture

> **Engineering Decision Record (EDR-02-01-RF):** Прийнято в Сесії 3. Незворотне рішення для масового виробництва.

### 5.1. Проблема: чому зовнішні антени неприйнятні

Попередня концепція передбачала підключення антени через **U.FL-конектор та гнучкий коаксіальний кабель**, що стандартно для макетних плат. При масштабуванні на **10,000+ вузлів** цей підхід несе неприйнятні операційні ризики:

| Ризик | Наслідок |
|---|---|
| **Вандалізм / дикі тварини:** кабель антени виступає назовні → легко обгризти або зрізати | Втрата зв'язку вузла, відсутність сигналу в Queen |
| **Складність збірки:** ручне підключення U.FL-конектора вимагає ~30 сек на вузол + ризик пошкодження | +833 людино-годин на 100,000 вузлів, неприйнятна ціна |
| **IP68 герметизація:** кабельний ввід є найслабшою точкою герметизації | Відмова герметизації → відмова вузла при першому дощі |
| **SWR/VSWR при ненаправленій антені:** кабель без антени → відбиття RF → миттєве знищення SX1262 PA | Необоротне пошкодження PCB |

**Висновок:** Зовнішня дротова антена є **несумісною** з вимогами масового виробництва та польових умов.

#### Компонент 2: Деталь 4 — PEEK Radome (Капсула-Радом / PEEK Crown)

Радом є **Четвертим Елементом** механічного стеку (після Деталей 1–3 коаксіального анкера). Він «насаджується» на M6-шліц Деталі 3 (Анод) і накриває всю електроніку, створюючи антивандальну герметичну "таблетку" діаметром ~20–30 мм на поверхні стовбура дерева.

```

│  Матеріал:      PEEK (Polyetheretherketone), Medical Grade      │
│                 Альтернатива: UV-стійкий полікарбонат (PC/ASA),  │
```

#### Механічна Інтеграція Деталі 4 (Zero-Touch Assembly)

Послідовність польового монтажу:
1. Працівник вкручує титановий анкер (Деталі 1–3) у підготовлений канал шестигранним ключем (M6)
2. Зверху кладе плату — вона сама знаходить контакти завдяки Pogo Pins (→ `02_02`)
3. Накручує (або фіксує байонетом) PEEK-кришку (Деталь 4) на зовнішню різьбу Деталі 3
4. O-ring EPDM затискається між Деталлю 3 та Радомом → IP68 вакуум для електроніки

**Жодних дротів, конекторів чи пайки в полі.** Керамічна антена опиняється в міліметрі від внутрішньої стінки PEEK-кришки і вільно випромінює сигнал у ліс.

**Що дає Деталь 4 системі:**

| Характеристика | Результат |
|---|---|
| **Антивандальність** | Зовні — лише гладка непомітна "таблетка" ∅20–30 мм. Неможливо відламати, за неї не зачепиться ведмідь чи гілка |
| **Масштабованість (Zero Touch)** | Заводська збірка: робот паяє SMD-антену на плату. Поле: вкрутити анкер → покласти плату → закрутити кришку |
| **Ідеальний КСВ** | Форма кришки та положення плати завжди однакові → антена працює в передбачуваному резонансі на всіх 10,000+ пристроях |
| **IP68 без кабельних вводів** | Монолітна конструкція, єдина точка герметизації — O-ring між Деталлю 3 та Радомом |

**Переваги PEEK проти альтернатив:**

| Матеріал | εr | tan δ | IP68 | Вартість | Рішення |
|---|---|---|---|---|---|
| **PEEK** | 3.2 | 0.003 | ✅ | Середня | **✅ Обрано** |
| ABS | 2.5 | 0.005 | ⚠️ | Низька | ❌ Не UV-стійкий |
| PC (Полікарбонат) | 2.9 | 0.006 | ✅ | Низька | ❌ Крихкий при −20°C |
| PTFE | 2.1 | 0.0002 | ✅ | Висока | ❌ Механічно м'який |
| Алюміній | — | — | ✅ | Низька | ❌ Екранує RF повністю |

### 5.3. Фізика Затухання Сигналу 868 МГц у Деревині/Воді

Антена розміщена **всередині** капсули, яка вмонтована в живе дерево. Сигнал проходить крізь PEEK-радом та кору. Це є фундаментальним фізичним обмеженням, яке неможливо обійти конструктивом — його потрібно враховувати в Link Budget.

#### Модель Затухання

```
Загальне затухання:
  L_total = L_FSPL + L_bark + L_wood_moisture + L_PEEK + L_body

де:
  L_FSPL  — Free Space Path Loss на відстані d [дБ]
            L_FSPL = 20·log(d) + 20·log(f) + 20·log(4π/c)
            @ 868 МГц, d=150 м: L_FSPL ≈ 77.8 дБ

  L_bark  — затухання у корі (суха кора, ~5 мм):
            ~2–5 дБ (залежить від вологості)

  L_wood_moisture — вологий підкірний шар (камбій):
            ~3–8 дБ (критично: рання весна / після дощу)

  L_PEEK  — затухання в PEEK-радомі (1.5 мм, εr=3.2):
            ~0.1–0.3 дБ (нехтується)

  L_total (worst case, волога кора): ~83–91 дБ @ 150 м
```

#### Link Budget

```
  TX Power (STM32WLE5JC SX1262):  +22 dBm
  TX Antenna Gain (ceramic SMD):   0 dBi
  EIRP:                           +22 dBm

  Path Loss (150 м, вологий ліс):  −91 дБ (worst case)

  RX Signal at Queen:             22 − 91 = −69 dBm

  SX1262 Sensitivity (SF7):       −124 dBm
  Link Margin:                    −69 − (−124) = +55 дБ ✅

  При SF12 (нижча швидкість, максимальна дальність):
  Sensitivity: −148 dBm → Link Margin = +79 дБ ✅✅
```

**Висновок:** Навіть при найгірших умовах (волога кора, 150 м hop) запас зв'язку становить **+55 дБ**. Керамічна SMD-антена є достатньою — зовнішня спрямована антена не потрібна і є конструктивно непридатною.

#### Критична Вимога: Keep-Out від Металевого Анкера

Титановий анкер (Ti-6Al-4V) є провідним матеріалом, що може **екранувати** антену. Вирішення:

- Антена розміщена на **верхньому** RF Deck — максимально далеко від металевого анкера (нижня частина капсули).
- Між анкером та PCB: ізоляційна прокладка (PEEK або поліімід) товщиною ≥ 2 мм.
- Анкер підключається до GND через Pogo Pins (не до RF-мережі) → є лише DC-з'єднанням, не RF-резонатором.

### 5.4. Zero-Touch RF — Переваги для Виробництва

| Параметр | U.FL + кабель (стара концепція) | Ceramic SMD + PEEK Radome (v2) |

## 🧩 6. Апаратні Хаки

Замість дорогих зовнішніх датчиків — вбудована периферія STM32:

1. **Температура:** Внутрішній ADC-канал STM32 (температурний сенсор у кристалі). Точність ±1 °C. Калібрується по двох точках (30 °C та 110 °C — константи в Flash STM32, TSENSE_CAL1/CAL2).

2. **Акустика без живлення (Zero-Power Wake):** П'єзодиск ZP-3/ZP-5 приклеєний до металевого дна капсули (акустичний контакт через анкер). Вібрація від бензопили або пожежі генерує сплеск напруги → BAT54S обмежує до 0–3.3 В → EXTI GPIO переривання → MCU прокидається з STOP2 апаратно, без постійного опитування.

3. **MPPT без зовнішнього сенсора:** BQ25570 сам вимірює VOC кожні 16 с (внутрішня логіка). Не потребує зовнішнього датчика напруги → економія BOM і площі плати.

## ⚠️ 10. Критичне Попередження: LoRa-Антена

> **КРИТИЧНО:** НІКОЛИ не подавайте живлення на плату Queen або Soldier, якщо LoRa-антена фізично не підключена до SMA/U.FL-порту або не припаяна (SMD-варіант).

Радіомодуль SX1262 містить потужний RF-підсилювач (+22 dBm вихід). Без антени переданий RF-сигнал не має куди "піти" і відбивається назад у мікросхему (висока VSWR). Це знищує RF front-end протягом мілісекунд — пошкодження незворотне.

- **Послідовність:** Спочатку підключаємо антену → потім подаємо живлення.
- **Правило:** Якщо антена відсутня — плата не готова до увімкнення.

### Золоте Правило: Спільна Земля

**Перш ніж торкатися будь-якого дроту:** підключіть кожен вивід GND кожного модуля, тримача батарейки та суперконденсатора до однієї довгої синьої лінії (шина мінуса) вздовж краю макетної плати. Усі електрони повинні мати єдину точку відліку, інакше система поводитиметься непередбачувано.

### Як Працює Макетна Плата

Під пластиком макетна плата містить металеві кліпсові рейки:

- **Центральна зона:** лунки згруповані в горизонтальні ряди по 5 (наприклад, ряд 10: стовпці A, B, C, D, E). Усі 5 лунок одного короткого ряду **фізично з'єднані** однією металевою смужкою — вставивши дріт у 10A та інший у 10C, ви отримуєте прямий електричний вузол.
- **Бічні шини** (червона `+` / синя `−`): проходять по всій довжині плати. Використовуються як шини живлення (`3.3V`) та землі (`GND`).

### Острів 1: Симулятор Дерева — Дільник Напруги

Перетворює 1.5 В від батарейки AA на ~44 мВ для симуляції ксилемного потенціалу.

**Формула дільника напруги:**

```
V_out = V_in × R2 / (R1 + R2)
V_out = 1.5 В × 100 Ом / (3300 Ом + 100 Ом) ≈ 0.044 В (44 мВ)
```

**Збирання:**

1. Вставте тримач батарейки у макетну плату. Перемикач **ВИМК**.
2. Підключіть чорний дріт (−) до синьої шини GND.
3. Підключіть червоний дріт (+) до вільної лунки — наприклад, ряд 5, стовпець A.
4. Вставте резистор 3.3 кОм від рядка 5A до рядка 10A.
5. Вставте резистор 100 Ом від рядка 10B до синьої шини GND.
6. **Магічна точка:** спільна металева смужка в ряді 10 тепер утримує ~44 мВ. Ряди 10C, 10D, 10E вільні та несуть той самий потенціал — використовуйте їх для подальшої розводки сигналу.

---

### Острів 2: Підсилювач Енергії — Генератор LTC3108

Бере 44 мВ і резонансно підвищує до 3–5 В за допомогою схеми Майсснера.

**Як це працює:** LTC3108 + трансформатор діють як гойдалка. 44 мВ входить у первинну обмотку → трансформатор наводить імпульс назад у мікросхему → мікросхема штовхає сильніше → тисячі циклів на секунду підвищують напругу. Конденсатор 330 пФ задає резонансну частоту ("маятник").

**Збирання (плата LTC3108, вставлена в ряди 20–30):**

1. **Живлення:** Перемичкою з'єднайте ряд 10 (~44 мВ) з виводом `VIN` LTC3108.
2. **GND:** Вивід `GND` LTC3108 → синя шина GND.
3. **Первинна обмотка (Coilcraft LPR6235, виводи 1 і 4):**
   - Вивід 1 трансформатора → той самий ряд що `VIN`.
   - Вивід 4 трансформатора → ряд із виводом `SW` LTC3108.
4. **Вторинна обмотка (виводи 2 і 3):**
   - Вивід 2 → синя шина GND.
   - **Резонансний конденсатор (330 пФ):** одна ніжка → ряд виводу 3 трансформатора; інша → ряд виводу `C1` LTC3108.
5. **Розв'язуючі конденсатори:**
   - 1 мкФ між рядом `VAUX` та синьою шиною GND.
   - 2.2 мкФ між рядом `VLDO` та синьою шиною GND.

**Вихід:** вивід `VOUT` LTC3108 тепер дає ~3.3–5 В при мікроамперному струмі → подайте на Острів 3.

---

### Острів 3: Менеджер Енергії + Резервуар — BQ25570 + Суперконденсатор

Накопичує краплю від LTC3108 у суперконденсаторі 0.47 Ф та забезпечує стабільний вихід 3.3 В.

**⚠️ Полярність критична.** Переплутавши полярність суперконденсатора, ви його знищите. Довша ніжка — `+` (анод); біла смуга на корпусі — `−` (катод).

**Збирання (модуль CJMCU-25570):**

1. **Живлення:** Перемичка з `VOUT` LTC3108 до `VIN` (або `VIN_DC`) BQ25570.
2. **GND:** `GND` BQ25570 → синя шина GND.
3. **Суперконденсатор:**
   - Довга ніжка (`+`) → вставте у вільний ряд та підключіть перемичкою до `VBAT` BQ25570.
   - Коротка ніжка (`−`) → безпосередньо у синю шину GND.
4. **Вихід:** Вивід `VOUT` BQ25570 дає стабільні 3.3 В, коли суперконденсатор заряджається до порогового рівня (~3.4 В). Підключіть до Острова 4.

**Що відбувається фізично:** BQ25570 накопичує суперконденсатор крапля за краплею. Коли `VBAT` перетинає внутрішній поріг, вбудований перетворювач (buck) відкривається та видає 3.3 В на `VOUT`. До цього моменту `VOUT` дорівнює 0 В — LoRa-модуль не увімкнеться.

---

### Острів 4: Мозок — LoRa-E5 Mini

Розмістіть LoRa-E5 mini на краю макетної плати для зручного доступу до Type-C-порту та роз'ємів програматора.

**Збирання:**

1. **GND:** Вивід `GND` LoRa-E5 → синя шина GND.
2. **Живлення:** Вивід `VOUT` BQ25570 → вивід `3V3` LoRa-E5.

Готово — енергетичний ланцюг зібрано.

---

### Протокол Першого Запуску

Після збирання **не вмикайте** батарейку одразу.

1. Встановіть мультиметр на режим DC-напруги. Торкніться щупів до ніжок суперконденсатора (+ і −).
2. Перевірте показання: `0.0 В` (розряджений).
3. Увімкніть перемикач батарейки.
4. Спостерігайте: `0.1 В … 0.5 В … 1.2 В …` — суперконденсатор заряджається мілівольт за мілівольтом. Холодний запуск зазвичай займає 15–30 хвилин.
5. Коли напруга перетне ~3.4 В, BQ25570 відкриє свій вихід.
6. Світлодіод LoRa-E5 блимне. Вузол Soldier живий — живиться від 44 мВ.

### Фізичне Підключення Програматора та Консолі

> **Примітка:** Детальна схема SWD/UART підключення також задокументована в `03_01_Firmware_Lifecycle_and_DMA` (розділ "Фізичне Підключення Апаратного Відладчика").

#### Фаза 0: Спільна Земля (Виконайте Першим)

1. Перемичка ST-LINK-V3MINIE `GND` → синя шина GND.
2. Перемичка FT232RL `GND` → синя шина GND.

Усі пристрої (Mac, ST-LINK, FT232RL, макетна плата) тепер мають спільний електричний потенціал.

#### Канал SWD — ST-LINK-V3MINIE (Прошивка / Налагодження)

| Вивід ST-LINK | Вивід LoRa-E5 | Призначення |
|---|---|---|
| `SWCLK` | `CLK` | Тактовий сигнал SWD — синхронізація передачі |
| `SWDIO` | `DIO` | Дані SWD — перенесення прошивки |
| `NRST` | `RST` | Скидання після прошивки (рекомендовано) |
| `T_VCC` | `3V3` | Лише опорна напруга — ST-LINK **не живить** плату |

> ST-LINK зчитує рівень `T_VCC`, щоб узгодити свою логічну напругу. Струм через цей вивід не подається.

#### Канал UART — FT232RL

**⚠️ Критична перевірка перед підключенням:** маленька перемичка на модулі FT232RL має бути встановлена у позицію **3.3V**, а не 5V. 5V на виводах UART STM32 призводить до миттєвого пошкодження.

UART використовує перехресне підключення TX/RX:

| Вивід FT232RL | Вивід LoRa-E5 | Напрямок |
|---|---|---|
| `RX` | `TX` | LoRa передає → адаптер отримує |
| `TX` | `RX` | Адаптер передає → LoRa отримує |
| `VCC` | *(не підключати)* | Плата вже живиться від BQ25570 |

Нижче задокументовано компоненти, які розглядалися під час архітектурних ітерацій та були **свідомо відхилені** для поточної архітектури TRL 6. Зберігаємо для контексту при майбутніх ревізіях.

### 7.1. ADS1220 — Зовнішній 24-бітний ADC (Texas Instruments)

**Характеристики:** 24-біт, SPI, duty cycling mode (120 нА у сні, пробудження за мілісекунди), вбудований генератор (нуль стабілізації), ~$6.00.

**Пропоноване застосування:** Прецизійне вимірювання напруги розімкнутого кола EBFC ($V_{OC}$) для діагностики деградації конденсатора vs деградації дерева.

**Чому відхилено:**
- Вбудований 12-бітний ADC STM32WLE5JC достатній для вимірювання `vcap_voltage` через внутрішній дільник напруги BQ25570 (VBAT_SEC вихід, масштабований до діапазону ADC 0–3.3 В; роздільна здатність ~0.8 мВ/LSB).
- Додаткові $6.00 до BOM (+54% вартість електроніки) не виправдані для базового функціоналу.
- Збільшує складність PCB (SPI routing, додаткові пасивні компоненти).
- Споживання 120 нА у сні не є проблемою, але кожен додатковий компонент зменшує надійність (MTBF).

**Перспектива (TRL 8+):** Може бути повернутий до BOM якщо знадобиться роздільна здатність <1 мВ для $V_{OC}$ діагностики. Див. також `02_04` §4.2 (Концепт Діагностики Деградації Конденсатора).

### 7.2. TPS22860 — Ultra-Low Leakage Load Switch (Texas Instruments)

**Характеристики:** SOT-23, 10 нА витік, фізично розриває лінію живлення сенсорів за сигналом від MCU, ~$0.50.

**Пропоноване застосування ("Кенозис" — фізичне спорожнення):** Замість програмного вимкнення сенсорів, TPS22860 фізично відрізає їх від живлення. MCU подає GPIO → живлення на сенсори з'являється → замір → живлення знімається. Струм у вимкненому стані: 10 нА (майже абсолютний нуль).

**Чому відхилено для поточного TRL 6:**
- Поточна архітектура **не має зовнішніх сенсорів**. STM32WLE5JC використовує лише вбудований ADC (канал температури, VREFINT, Vcap). Немає зовнішніх пристроїв для "відрізання".
- STOP2 Deep Sleep STM32WLE5JC вже забезпечує 2.1 µA. Додатковий load switch економить ~0.1 µA — маргінальний виграш при 0.47 F EDLC з генерацією 15-20 µA від EBFC.
- Додатковий GPIO + компонент для маргінального виграшу порушує принцип мінімізації BOM.

**Перспектива:** Стає необхідним компаньйоном, якщо до BOM буде доданий зовнішній ADC (ADS1220) або інші зовнішні сенсори. У зв'язці ADS1220 + TPS22860 забезпечує ідеальний duty cycling: GPIO ON → ADS1220 прокидається → SPI замір за мілісекунди → GPIO OFF → 10 нА.
