## S7. Reproduction recipe

```bash
# 1. the recorded environment (osx-arm64) — a REPLAY of the exact package set
conda create -n silken_md_replay --file tools/in_silico/environment.computed.explicit.txt
# 2. the maintained lock — a REPRODUCTION attempt (PySCF 2.13.1 ≠ the 2.11.0 the caches came from;
#    metal-in-continuum numbers move with its PCM fix — Methods §2.7)
conda-lock install -n silken_md_lock tools/in_silico/conda-lock.yml
# 3. the pins: every headline number in SUMMARY / L3 / the paper equals its owner cache
cd tools/in_silico && python -m pytest tests -q
# 4. the paper assets, from the caches only (no DFT): figures · tables · this manifest
python scripts/60_paper_figures.py && python scripts/61_paper_tables.py && python scripts/72_paper_supporting_information.py
# 5. a re-run of any numbered DFT/MD script writes a NEW cache — compare it to the committed one field by field
```

A verified SHA-256 of every file above is what makes step 3 meaningful: the pins prove the docs match the caches, this manifest proves the caches are the committed bytes.
