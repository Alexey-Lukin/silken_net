# Pre-Submission Self-Review Checklist (hard-science)

**Призначення.** Тонкий self-review gate для рукописів плану `00_02 §2.1` (Статті 1–24a) — від
квантової хімії (Стаття 1) до formal-verification / RF / стохастики, а також зовнішньої
фізики (DM-EFT → JCAP/PRD). Прогнати **до сабміту** або **до передачі співавтору**. Це
**copilot-not-pilot**: інструмент не пише й не рецензує за тебе — він робить сліпі плями
видимими; рішення «accept / ще раунд» завжди твоє.

**Походження.** Витяг *ідей* (не коду) з `academic-research-skills` (Imbad0202, CC-BY-NC) —
наша тонка реімплементація під hard-science, сплетена з власним etos'ом, що вже стоїть у
Статті 1 (`00_02 §2.1`): чесна рамка «механізм + межі методу» замість «validation»-overclaim.

---

## Gate 1 — Citation integrity [HARD, перед сабмітом]

Найдорожчий gate: одна вигадана цитата = desk-reject у Q1.

- [ ] Кожна цитата має **верифікований DOI / arXiv-id** (не «схоже на правду» з пам'яті моделі).
- [ ] **Gray-zone = FAIL.** Не можеш підтвердити, що джерело існує → воно НЕ йде в статтю
      (не «uncertain», а геть).
- [ ] **Жодного vibe-citing** — не зшивати 2–3 реальні папери в одну неіснуючу цитату
      (найважче спіймати очима).
- [ ] In-text ↔ reference list: нуль orphan'ів (кожна цитата присутня в обох).

## Gate 2 — П'ять незалежних лінз (не перехресних)

Прогнати чернетку кожним кутом окремо; не зливати в розмите «загалом непогано».

- [ ] **EIC** — fit журналу, новизна, significance (Стаття 1: *J. Phys. Chem. B* primary).
- [ ] **Methodology** — rigor, відтворюваність, числові методи. Для in-silico: чи відтворить
      чужий з `protocols/ebfc/in_silico/`?
- [ ] **Domain** — повнота літератури, теор. рамка, що саме incremental.
- [ ] **Perspective** — крос-дисциплінарність, чесний «so what?».
- [ ] **Devil's Advocate** — найсильніший контраргумент проти ядра (Стаття 1 робить це сама:
      «FADH₂→Os uphill у кожному методі» подано як **межу методу**, не як діру).

## Gate 3 — Anti-sycophancy + рівні доказів

- [ ] Methodology-діра ⇒ rigor **не може** бути «високо». Не інфлювати оцінку заради комфорту.
- [ ] Рівні доказів **відносні до поля**: peer-reviewed > preprint > gray; arXiv-препринт у
      фізиці ≠ блог. PRD/JCAP-tier для DM-EFT, *J. Phys. Chem. B*-tier для EBFC.

## Gate 4 — Чесні межі (наскрізний etos)

- [ ] **«Validation» = reviewer-landmine.** Якщо обчислення експонує межу методу — кажи
      «механізм + межа», не «валідація» (рівно як переформульовано Статтю 1, 2026-06-05).
- [ ] **in-silico ≠ TRL.** Аналітичний PoC ≠ фізичний доказ; стан TRL чесний (System TRL 3).
- [ ] Явна **Limitations**-секція; межі подані як новизна, не схована діра.
- [ ] **AI-disclosure** присутній (venue-specific) — `00_01 §8` publish-to-protect, не приховування.

## Gate 0 — RQ sanity [опційно, до письма]

- [ ] **FINER**: Feasible / Interesting / Novel / Ethical / Relevant. Питати, **не** пропонувати
      гіпотези за автора.

## Де що лежить (павутина, не лише 00_02)

| Що | Дім |
|---|---|
| План 24 статей + per-paper рамка | `00_02 §2.1` (ЧНУ 1–10 · ЧДТУ §1B 11–14 · спільні §1C 15–24a) |
| IP-постава / publish-to-protect / AI-disclosure | `00_01 §8` + `protocols/anchor/defensive_disclosure.md` |
| Реальні числа/claims (Стаття 1 ①②③④) — One-Home | `protocols/ebfc/in_silico/SUMMARY.md` + `PIPELINE_STATUS.md` |
| Staffing / AI-clones / хто що пише | `00_03 §3.6` |
| Інституції / співавтори (Мінаєв, Гусак) | `00_02` |
| Paper-трекер (UNI.3, HW.3.IS, CHEM.*, E.59) | `00_07` |

## Чим це НЕ є

- **НЕ** peer review — це self-review aid; справжня рецензія = люди.
- **НЕ** автопис — gate'и роблять сліпі плями видимими, автор вирішує.
- **НЕ** runtime-гейт — це дисципліна, не CI (на відміну від `docs:check_refs`).
- Макс **2 раунди** само-ревізії → далі «Acknowledged Limitations», не безкінечне шліфування.
