## Usage Notes

1. Run each query set on **PATENTSCOPE** (WIPO), **Espacenet** (EPO), and **Google Patents**
2. Filter by publication date: last 20 years (2006-2026)
3. Focus on claims that combine **two or more** of our innovations (gyroid + EBFC + LoRa + blockchain)
4. Document hits in a spreadsheet: patent number, title, assignee, key claims, overlap assessment
5. Any patent with >70% claim overlap → consult with TISC ЧНУ for design-around strategy

> **Silken Net differentiator:** No prior art combines ALL of: (a) Ti-6Al-4V gyroid in living tree, (b) FAD-GDH/Os MET + laccase/ZIF DET EBFC, (c) Lorenz attractor bio-contract on mruby VM, (d) 12-chain Web3 Proof of Growth. Each individual component has prior art; the **system-level combination** is novel.
