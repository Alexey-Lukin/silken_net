## 🧪 2. Протоколи R&D (Hard Science Protocols)

### Протокол «Quantum-Sap» (Школа Мінаєва)

**Мета:** Квантово-хімічне обґрунтування генерації потокового потенціалу на межі Ti-6Al-4V / ксилемний сік.

**Кроки:**
1. **Моделювання:** Квантово-хімічний розрахунок (DFT/TDDFT) адсорбції молекул яблучної та лимонної кислот на TiO₂-поверхні анкера
2. **Енергетика:** Розрахунок квантового виходу електронів при розриві подвійного електричного шару
3. **Синтез:** Створення ідеально точного штучного ксилемного соку *Pinus sylvestris* (Черкаський бір) для тестів in vitro (pH 4.5–5.5)
4. **Оптимізація:** Визначення оптимальної оксидної структури (TiO₂ morph) для максимізації генерованого потенціалу

**Очікуваний результат:** Наукова стаття Q1 + технічний висновок для whitepaper: _"Механізм генерації потокового потенціалу підтверджено квантово-хімічним моделюванням"_

---

### Протокол «Long-Term Integrity» (Школа Гусака)

**Мета:** Математично довести довгострокову цілісність анкера (еквівалент 20–40 років за 3 місяці).

**Принцип Арреніуса (Arrhenius Acceleration):**
```
t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))

При Ea ≈ 0.7–1.0 eV (для Ti-сплавів у рідинах):
4 тижні @ 40°C ≈ 1 рік у лісі @ 15°C
12 тижнів @ 40°C ≈ 3–5 років у лісі
```

**Склад симульованого ксилемного соку (погоджено з біо-хабом):**

| Компонент | Концентрація | Призначення |
|---|---|---|
| pH | 5.0–5.5 | Кисле середовище ксилеми |
| Яблучна кислота (malic acid) | 1–5 мМ | Первинний органічний хелатор |
| Щавлева кислота (oxalic acid) | 0.5–2 мМ | Вторинний хелатор |
| KNO₃ (K⁺) | 2–5 мМ | Домінантний катіон ксилеми |
| CaCl₂ (Ca²⁺) | 0.5–2 мМ | Структурний катіон |
| MgSO₄ (Mg²⁺) | 0.2–1 мМ | Кофактор ферментів |
| Температурний цикл | 20–40°C | Добові коливання лісу |

**Механічний стрес (Fretting Simulation):**
- Частота: 1–5 Hz (реальна частота гойдання дерева на вітрі)
- Амплітуда: 0.1–1 мм (характерне зміщення стовбура)
- Навантаження: 0.5–5 N (осьове і бокове)

**Аналітичні методи:**
- **ICP-MS:** Вивільнення іонів Ti, Al, V у розчин (ціль: < 0.1 мкг/см²)
- **SEM/EDS:** Морфологія поверхні до/після тесту
- **EIS (Electrochemical Impedance Spectroscopy):** Корозійний опір покриття
- **XPS:** Хімічний стан поверхневого оксиду Ti

**Investor-Grade Claim:** _"Ti-6Al-4V gyroid anchor demonstrates < 0.1 µg/cm² ion release after equivalent 5-year accelerated aging test in synthetic xylem sap (Pinus sylvestris, Cherkasy)"_

**Мета:** Надати Lorenz Attractor реальний Baseline від живого лісу для розмежування норми/аномалії.

**Кроки:**

2. Визначення точного хімічного складу ксилемного соку (сезонні варіації)
3. Калібрування порогових значень Атрактора: `CRITICAL_Z_MIN`, `CRITICAL_Z_MAX`, `OPTIMAL_Z_TARGET` для Черкаського регіону
