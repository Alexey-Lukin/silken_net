# 08_01: Університетські R&D Протоколи (Тверда Наука)

## 🎯 Мета

Фундаментальна верифікація фізико-хімічних процесів на межі «Метал-Дерево» (Titanium-Xylem Interface) силами трьох провідних наукових шкіл Черкаського національного університету імені Богдана Хмельницького. Використання академічної експертизи світового рівня для доведення біосумісності, довговічності та енергетичної ефективності гіроїдного анкера. Результат: акредитовані лабораторні дані для whitepaper, pitch deck та сертифікаційних документів.

> **Контекст:** Архітектор — випускник ФОТІУС ЧНУ (2011, спеціальність ПЗАС / «Програмне забезпечення автоматизованих систем»). Повернення як CTO міжнародного deep-tech проєкту. Це не холодні продажі — це повернення випускника з конкретним R&D-полігоном для університету.

- Це дозволить науково пояснити, чому саме Ti-6Al-4V генерує ~500 мВ у кислому середовищі, та оптимізувати поверхню для підвищення потенціалу до 600–800 мВ при збереженні стабільності

Мінаєва) зможе доповнити TDDFT-моделюванням електронних спектрів EBFC-комплексу — це може стати спільною подружньою публікацією Q1.»

**Конкретний запит до школи Мінаєва:**

## 🧪 2. Протоколи R&D (Hard Science Protocols)

### Протокол «Quantum-Sap» (Школа Мінаєва)

**Мета:** Квантово-хімічне обґрунтування механізму генерації потокового потенціалу на межі Ti-6Al-4V / ксилемний сік для ефективної роботи Enzymatic Bio-Fuel Cell з урахуванням альтернативних ферментів (FAD-GDH на аноді та Laccase + laccase-like nanozymes на катоді).

**Кроки:**
1. **Моделювання:** Квантово-хімічний розрахунок (DFT/TDDFT) адсорбції яблучної та лимонної кислот на TiO₂-поверхні анкера.
2. **Енергетика:** Розрахунок квантового виходу електронів при розриві подвійного електричного шару та механізму charge transfer для GOx, FAD-GDH та Laccase/nanozyme систем.
3. **Синтез середовища:** Створення точного штучного ксилемного соку Pinus sylvestris (на основі даних Черкаського бору) для in vitro тестів (pH 4.5–5.5)
4. **Оптимізація:** Визначення оптимальної морфології та структури оксидної плівки TiO₂ для максимізації потенціалу та стабільності в кислому середовищі

**Очікуваний результат:** Наукова стаття Q1 + технічний висновок для whitepaper і pitch deck:
"Механізм генерації потокового потенціалу на межі Ti-6Al-4V / ксилемний сік підтверджено квантово-хімічним моделюванням (DFT) з урахуванням FAD-GDH та laccase-like nanozymes."

### Протокол «Long-Term Integrity» (Школа Гусака)

**Мета:** Математично довести довгострокову цілісність анкера (еквівалент 20–40 років за 3 місяці).

**Принцип Арреніуса (Arrhenius Acceleration):**
```
t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))

При Ea ≈ 0.7–1.0 eV (для Ti-сплавів у рідинах):
4 тижні @ 40°C ≈ 1 рік у лісі @ 15°C
12 тижнів @ 40°C ≈ 3–5 років у лісі
```

**Склад симульованого ксилемного соку (погоджено з біо-хабом):**

| Компонент | Концентрація | Призначення |
|---|---|---|
| pH | 5.0–5.5 | Кисле середовище ксилеми |
| Яблучна кислота (malic acid) | 1–5 мМ | Первинний органічний хелатор |
| Щавлева кислота (oxalic acid) | 0.5–2 мМ | Вторинний хелатор |
| KNO₃ (K⁺) | 2–5 мМ | Домінантний катіон ксилеми |
| CaCl₂ (Ca²⁺) | 0.5–2 мМ | Структурний катіон |
| MgSO₄ (Mg²⁺) | 0.2–1 мМ | Кофактор ферментів |
| Температурний цикл | 20–40°C | Добові коливання лісу |

**Механічний стрес (Fretting Simulation):**
- Частота: 1–5 Hz (реальна частота гойдання дерева на вітрі)
- Амплітуда: 0.1–1 мм (характерне зміщення стовбура)
- Навантаження: 0.5–5 N (осьове і бокове)

**Аналітичні методи:**
- **ICP-MS:** Вивільнення іонів Ti, Al, V у розчин (ціль: < 0.1 мкг/см²)

#### Умови тестового стенду (повний протокол)

| Параметр | Значення | Обґрунтування |
|----------|---------|--------------|
| Температура | 20–40°C циклічно | Добовий цикл лісу; прискорення за Arrhenius |
| Механічний стрес | вібрація 1–5 Hz, амплітуда 0.1–1 mm | Імітація вітрового навантаження (fretting corrosion) |
| Тривалість тесту | 4–12 тижнів | 4 тижні ≈ 1 рік; 12 тижнів ≈ 5 років за Arrhenius |
| Електрохімічна стимуляція | ~10 µA/cm² | Анодне розчинення без пошкодження структури |
| Зразки | по 3–5 гіроїдних анкерів | Статистична вибірка |

#### Розрахунок масштабу Arrhenius

```
t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))

Ea ≈ 0.7–1.0 eV (активаційна енергія корозії Ti-сплавів)
T_field = 293 K (20°C, ліс)
T_lab = 313 K (40°C, контрольована піч)

12 тижнів @ 40°C + fretting ≈ 5 років у лісових умовах
```
