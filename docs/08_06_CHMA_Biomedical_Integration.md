# 08_06: ЧМА — Біомедична Валідація Ксилемоінтеграції та EBFC

## 🎯 Мета

Формалізація академічної співпраці з **Черкаською медичною академією (ЧМА)** за чотирма напрямами:

1. **Біохімія EBFC Gen 2.0 та іммобілізація ферментів** — валідація протоколу іммобілізації **деглікозильованої FAD-GDH** (анод, без H₂O₂) та **Laccase/ZIF-nanozyme** гібриду (катод) на макропористій поверхні Ti-6Al-4V у кислому середовищі ксилемного соку (pH 4.5–5.5); оптимізація захисних шарів **Genipin-Chitosan-CNC** (нетоксичний рослинний зшивач + псевдопластика) та **Nafion-g-PSBMA** (цвітеріонна мембрана, σ = 45.2 мС/см, UCST winter-lock) для досягнення терміну служби 20–25 років
2. **Токсикологія металів та фретингова корозія** — хімічна та токсикологічна експертиза вивільнення іонів V та Al зі сплаву Ti-6Al-4V при фретинговій корозії; оцінка впливу металів на метаболізм дерева (ксилемний транспорт, фотосинтез, кореневе поглинання)
3. **Біосумісність та клітинна інтеграція (Ксилемоінтеграція)** — медична аналогія: реакція живої тканини на чужорідне тіло (stress-shielding, інкапсуляція, запальна реакція); адаптація принципів біомедичних імплантів (остеоінтеграція → ксилемоінтеграція) для оптимізації CODIT-сумісності анкера
4. **Self-healing покриття та фармацевтична хімія** — валідація або розробка мікрокапсул з 8-гідроксихіноліном (8-HQ) для самовідновлювального антикорозійного покриття; фармацевтична хімія інгібіторів корозії в біологічних середовищах

ЧМА — єдиний медичний ВНЗ у Черкаському регіоні, що поєднує **фармацевтичну хімію**, **фізіологію стресу** та **токсикологію**. Чотири попередні академічні партнери (ЧНУ — фізико-хімічна верифікація хардверу; ЧНУ ФОТІУС — кіберфізична валідація firmware/backend; ЧДТУ — Data Science, RF-верифікація, акустика; ЧІПБ — пожежна безпека, параметричне страхування, SOP) покривають повний цикл від анкера до блокчейну, але **жоден з них не має компетенції в біохімії ферментативних реакцій, токсикології металів в біологічних системах та фармацевтичній хімії захисних покриттів**. ЧМА закриває цю критичну прогалину — забезпечує медико-біохімічну основу для довговічності хардверу.

> **Контекст:** Silken Net вживляє титановий анкер Ti-6Al-4V у живе дерево на 20+ років. EBFC генерує ~500 мВ із ксилемного соку через ензимний каталіз ([`01_03`](01_03_EBFC_Enzymatic_Bio_Fuel_Cell)). Дерево реагує за протоколом CODIT — формує бар'єрні зони навколо чужорідного тіла ([`01_04`](01_04_CODIT_and_Xylemointegration)). Фретингова корозія від вітру вивільняє іони V/Al з Ti-6Al-4V ([`01_02`](01_02_Ti_6Al_4V_Metallurgy_and_DMLS)). Self-healing покриття з мікрокапсулами 8-HQ має автономно залатати мікротріщини. Всі ці процеси відбуваються на перетині біохімії, токсикології та фармацевтичної хімії — **саме в зоні компетенції ЧМА**.

### 1.1. Губенко Інна — Макро-рівнева Біосумісність та Ксилемоінтеграція

**Посада (потребує верифікації):** Ректор ЧМА, професор
**Науковий ступінь (потребує верифікації):** Кандидат медичних наук
**Спеціалізація:** Загальна медицина, біосумісність імплантів, клітинна реакція на чужорідне тіло

**Точка перетину зі Silken Net:**

Silken Net вживляє **тризонний коаксіальний титановий анкер** ([`01_01`](01_01_Coaxial_Gyroid_Topology_and_PEEK), загальна довжина ~80–120 мм, пористість гіроїдної анодної секції 65%) у живе дерево. Процес **ксилемоінтеграції** ([`01_04`](01_04_CODIT_and_Xylemointegration)) є прямою аналогією **остеоінтеграції** у зубних та ортопедичних імплантатах людини:

| Медичний імплант (остеоінтеграція) | Silken Net анкер (ксилемоінтеграція) |
|-------------------------------------|---------------------------------------|
| Ti-6Al-4V → кістка | Ti-6Al-4V → ксилема дерева |
| Пористість скаффолда 50-70% | Гіроїдна пористість 60-70% ([`01_01`](01_01_Coaxial_Gyroid_Topology_and_PEEK)) |
| Остеобласти проростають у пори | Калюс (CODIT Фаза 2) проростає у макропори |
| Stress-shielding → резорбція кістки | Stress-shielding → деградація ксилеми |
| Фібротична капсула (інкапсуляція) | CODIT Стіна 4 (бар'єрна зона) |
| Запальна реакція → фіброз | Фенольні сполуки + смола (Фаза 1) |
| pH рановий ексудат ~5.5-7.4 | pH ксилемний сік ~4.5-5.5 |

**Губенко як ректор має адміністративний ресурс** для відкриття доступу до кафедр фармацевтичної хімії та фізіології — аналогічно ролі Декана Онищенка у ФОТІУС ([`08_02`](08_02_Cybernetic_and_Mathematical_Validation) §1.7).

### 1.2. Боєчко Владислав — Фізіологія Стресу та Біомаркери

**Посада (потребує верифікації):** Професор ЧМА
**Спеціалізація:** Фізіологія стресу, маркери виснаження організму

**Точка перетину зі Silken Net:**

Silken Net використовує **Lorenz Attractor** ([`03_04`](03_04_mruby_Lorenz_Attractor)) для класифікації здоров'я дерева: `bio_status = :homeostasis / :stress / :anomaly`. Класифікація базується на Z-значенні атрактора, яке обчислюється з фізичних параметрів (`delta_t`, `temperature_c`, `acoustic_events`). Але **біохімічні маркери стресу дерева** (аналогічні кортизолу, адреналіну та маркерам оксидативного стресу у людини) не враховані в моделі.

**Поточний стан у кодбейсі:**

```ruby
# app/services/silken_net/attractor.rb — класифікація здоров'я
# Z-value визначає bio_status:
#   Z < CRITICAL_Z_MIN (2.0)  → :stress (ранній сигнал)
#   Z > CRITICAL_Z_MAX (45.0) → :anomaly (критичний стрес)
#   else                      → :homeostasis (здоровий хаос)

# app/services/insight_generator_service.rb — stress_index (0-1)
# Гібрид: RF predict_proba + rule-based fallback
# Поріг слешингу: stress_index ≥ 0.83

# firmware/bio_contracts/bio_contract.rb — firmware класифікація
# growth_points = (reward / 2).clamp(5, 31) при homeostasis  [FW.29-PACK 5-bit wire]
```

**Проблема:** Модель «прихованого стресу» (коли дерево зовні здорове, але внутрішньо вже деградує) працює лише через `delta_t` (час заряду іоністора від EBFC). Боєчко може транспонувати медичні маркери «латентного виснаження» на рослинну систему:

| Медичний маркер стресу (людина) | Аналог у дереві | Вимірювання Silken Net |
|---------------------------------|-----------------|------------------------|
| Кортизол (хронічний стрес) | Абсцизова кислота (ABA) | Непрямо: `delta_t` зростає при ABA-індукованому закритті продихів |
| Лактат (анаеробний метаболізм) | Етанол (анаеробне дихання коренів) | Непрямо: `z_value` зміщується при зниженні O₂ в ксилемі |
| ROS (оксидативний стрес) | H₂O₂ та O₂⁻ (при посусі, патогенах) | Непрямо: деградація EBFC ферментів → зниження `voltage_mv` |

**Завдання В: Калібрування sap-term у calculate_stress_index_heuristic**

✅ **Оновлено (2026-05-29):** евристика більше НЕ сліпа до sap — додано signed below-baseline sap-term (`sap_stress_contribution`), **inert доки калібрування не задасть** `STRESS_SAP_LOW_THRESHOLD` + `STRESS_SAP_WEIGHT` (ENV; жодного вгаданого порогу в live slashing). Високий sap (вигор) ніколи не штрафується; внесок обмежений так, що sap **корелює, але не слешить сам**. Симетрично додано **acoustic/cavitation-term** (`acoustic_stress_contribution`); sap+acoustic — correlated drought → беруться через **max(), не суму**. Лишилось завдання Боєчка — медично обґрунтовані **поріг + вага** (для sap):

```ruby
# РЕАЛІЗОВАНО (app/services/insight_generator_service.rb)
def calculate_stress_index_heuristic(max_status, avg_temp, max_acoustic, avg_z, sap_signed_deviation = 0.0)
  return 1.0 if max_status >= 2  # anomaly/tamper → max stress
  base_stress = (max_status == 1 ? 0.6 : 0.0)
  base_stress += 0.2 if avg_z.abs > 2.0
  base_stress += 0.1 if avg_temp > 35.0 || avg_temp < -5.0
  # sap↓ + cavitation↑ = correlated drought → max(), не сума; inert доки ENV-калібрування
  base_stress += [ sap_stress_contribution(sap_signed_deviation),
                  acoustic_stress_contribution(max_acoustic) ].max
  [ base_stress, 0.99 ].min
end
# ML-шлях незмінний: sap_deviation (abs) лишається фічею моделі
# [avg_temp, avg_vcap, avg_z, sap_deviation, max_acoustic].
```

```
     - Фітотоксичність: при яких концентраціях 8-HQ шкодить рослинним клітинам?
  2. Оцінка дози вивільнення — ⚠️ це ГОСТРИЙ (acute) burst, НЕ хронічна концентрація:
     - 8-HQ вивільняється ЛИШЕ в момент розриву мікрокапсули (мікротріщина) —
       одноразовий мікро-burst у локальному об'ємі камбію навколо тріщини, а НЕ
       постійний потік (на відміну від хронічного вивільнення V). До того ж 8-HQ
       одразу хелатує Ti²⁺/Ti³⁺ у **інертний комплекс** → вільного 8-HQ майже не лишається.
     - Рахувати: безпеку РАЗОВОГО burst у локальному об'ємі (peak local µg), а не
       стаціонарну µg/L у потоці соку. Порівняти peak з гострим фітотоксичним порогом.
  3. Альтернативні інгібітори (якщо 8-HQ небезпечний):
     - Бензотриазол (BTA) — менш токсичний, але гірша хелатація Ti
     - Цеолітні мікрокапсули з природними танінами (дерево-сумісний інгібітор)
     - Молібдат натрію (Na₂MoO₄) — мікроелемент для рослин
```

**Завдання В: Кодбейс-інтеграція — TreeFamily та видо-специфічні токсикологічні пороги**

```
Модель TreeFamily (app/models/tree_family.rb) вже має JSONB поле biological_properties:
  store_accessor :biological_properties,
    :sap_flow_index,          # індекс потоку ксилеми для виду
    :bark_thickness,           # товщина кори (мм)
    :foliage_density,          # щільність крони
    :fire_resistance_rating    # рейтинг пожежної стійкості

Суховой додає токсикологічні пороги для кожного виду (Pinus, Quercus, Fagus):
  store_accessor :biological_properties,
    :vanadium_lc50_ug_l,    # LC50 V⁵⁺ для ксилеми конкретного виду (µg/L)
    :aluminum_lc50_ug_l,    # LC50 Al³⁺ (µg/L)
    :safety_margin_v,        # Safety Margin = LC50(V) / C_measured (ціль > 100×)
    :8hq_phytotox_threshold  # поріг фітотоксичності 8-HQ (µg/L)

Результат: видо-специфічні токсикологічні пороги (LC50) зберігаються у TreeFamily
  як КОНСТАНТИ дизайну (з lab ICP-MS Гусака/Суховоя — ex-situ, in vitro).

  ⚠️ ICP-MS — це стаціонарний лабораторний прилад; його НЕ можна читати на борту
  анкера чи в backend у лісі. ion_risk_index НЕ обчислюється з live ICP-MS.
  Бортовий проксі деградації (корозія / руйнування TiO₂-плівки) = падіння Vcap
  + аномальне зростання delta_t при незмінній швидкості потоку соку. LC50-пороги
  лише задають, наскільки консервативним має бути дизайн покриття (Safety Margin).
```

### 1.5. Глущенко Олександр — Self-Healing Покриття (8-HQ Мікрокапсули)

**Посада (потребує верифікації):** Доцент ЧМА
**Науковий ступінь (потребує верифікації):** Кандидат фармацевтичних наук
**Спеціалізація:** Фармацевтична хімія, мікрокапсулювання, контрольоване вивільнення лікарських засобів

**Точка перетину зі Silken Net:**

Self-healing покриття ([`01_02`](01_02_Ti_6Al_4V_Metallurgy_and_DMLS) §3) — це **мікрокапсули з інгібітором**, вбудовані у захисний шар анкера. Концепт:

```
Фретингова корозія (вітер) → мікротріщини у ZnO-Ta покритті
   (лише на неактивних поверхнях: зовнішня сорочка Zone 3, торці PEEK Zone 2) →
розрив мікрокапсул (∅ 1-50 µm) → вивільнення 8-HQ →
хелатація Ti²⁺/Ti³⁺ → локальна пасивація → «загоєння» без втручання
```

> ⚠️ **Zone restriction:** Self-healing мікрокапсули наносяться **тільки** на неактивні поверхні анкера (карта обмежень `01_02` §3.6). На гіроїдні стінки Zone 1 і на каталітичну поверхню Zone 3 — заборонено, бо діелектричний шар блокує DET між ферментами та титаном.

**Фармацевтична хімія мікрокапсулювання** — це рутинна технологія фармацевтичного виробництва (ентеросолюбільні капсули, пролонговані форми, ін'єкційні мікросфери). Глущенко може адаптувати стандартні фармацевтичні методи до унікальних умов ксилемного середовища.

**Конкретний R&D-запит:**

**Завдання А: Синтез та характеризація 8-HQ мікрокапсул**

```
Параметри (з 01_02 §3, для верифікації/оптимізації Глущенком):

  Оболонка: карбамід-формальдегідна (UF) або ПММА (PMMA)
  Діаметр: 1-50 µm (менші = щільніший шар)
  Вміст 8-HQ: 10-30 wt.%
  Метод: in-situ полімеризація (стандартний лабораторний протокол)
  Міцність на розрив: < 1 МПа (мікротріщини від фретингу мають розривати)

Завдання Глущенка:
  1. Синтез мікрокапсул методом in-situ полімеризації:
     - Оптимізація UF (простіше) vs PMMA (стабільніше при pH 4.5-5.5)
     - Характеризація SEM: розмір, однорідність, товщина оболонки
     - Вимір encapsulation efficiency (EE%): скільки 8-HQ реально всередині?
  2. Профіль вивільнення:
     - В синтетичному ксилемному соку (08_01 §2) при pH 5.0, T = 25°C
     - Без тріщин: <5% вивільнення за 30 днів (мікрокапсули мають "мовчати")
     - При механічному навантаженні 0.5-1 МПа: >80% вивільнення за 1 годину
  3. Стабільність оболонки:
     - 12 тижнів у ксилемному соку (без тріщин): чи не деградує UF/PMMA?
     - Вплив температурних циклів 20-40°C на цілісність
  4. Інтеграція у покриття:
     - Варіант А: додавання 1-5 г/Л мікрокапсул у PEO-електроліт (01_02 §3)
     - Варіант Б: layer-by-layer нанесення поверх ZnO-Ta + PVA/PEI зв'язка
     - Визначення оптимальної концентрації (баланс: healing capacity vs. міцність шару)
```

**Завдання Б: Альтернативні інгібітори (якщо 8-HQ фітотоксичний)**

```
Контекст: Суховой (§1.4) оцінить фітотоксичність 8-HQ.
  Якщо 8-HQ виявиться токсичним для дерева → Глущенко розробляє альтернативу.

Кандидати:
  1. Бензотриазол (BTA): класичний інгібітор для Cu/Fe, потребує перевірки на Ti
  2. Таніни (рослинного походження): природно присутні в деревині,
     нетоксичні, але слабша хелатація Ti vs 8-HQ
  3. Полігексаметиленгуанідін (ПГМГ): антимікробний + інгібіторний
  4. Молібдат натрію (Na₂MoO₄): мікроелемент + інгібітор
```

> _"Інно Валеріївно, я — розробник кіберфізичної системи моніторингу лісів. Ми фактично створюємо «зубний імплант для дерева» — пористий титановий скаффолд, що проростає ксилемою. Клітинна реакція дерева на чужорідне тіло — stress-shielding, інкапсуляція — це ваша зона компетенції як медичного науковця. Ми хочемо зробити ЧМА офіційним біомедичним партнером першої в Україні IoT-платформи для лісів — з публікаціями Q1 у Biomaterials та Acta Biomaterialia."_

Пріоритетний науковий партнер: стаття 28 (Biosensors and Bioelectronics Q1) — найближча до публікації, оскільки in vitro протокол не потребує спеціального обладнання, тільки фармацевтичний стенд ЧМА.

Ваш досвід з іммобілізацією ферментів та захисними матрицями — це єдине, чого мені не вистачає для whitepaper. Це стаття Biosensors and Bioelectronics Q1."_
