## 🧪 Прототипна Зборка на Breadboard (Legacy LTC3108-based)

### Золоте Правило: Спільна Земля

**Перед будь-яким підключенням:** усі `-` (GND) від усіх плат, батарейок та іоністора — в єдину **синю лінію** (шину) вздовж краю Breadboard. Без спільної землі логічні рівні перетворяться на хаос.

### Як Працює Breadboard (Внутрішній API)

Під пластиком Breadboard ховаються металеві рейки-кліпси:
- **Центральна частина:** горизонтальні рядки по 5 отворів (A-B-C-D-E). Всі 5 отворів одного рядка фізично з'єднані однією металевою пластиною. Вставити дріт у `10A` і `10C` = з'єднати їх напряму.
- **Крайні лінії (червона/синя):** вертикальні шини, з'єднані по всій довжині. Синя = GND, червона = VCC.

> `variable = 44_mV` ≡ увіткнути перемичку з рядку з 44 мВ у рядок з піном VIN мікросхеми.

### Острів 1: Симулятор "Дерева" (Дільник Напруги 1.5V → 44 мВ)

**Мета:** Імітувати ксилемний потоковий потенціал EBFC (44 мВ) з батарейки AA (1.5V) для лабораторних тестів без живого дерева.

**Компоненти:**
- Батарейка AA 1.5V з відсіком та тумблером
- Резистор **R1 = 3.3 кОм** (3300 Ом)
- Резистор **R2 = 100 Ом**

**Формула дільника напруги:**

$$V_{out} = V_{in} \times \frac{R_2}{R_1 + R_2} = 1.5\text{ В} \times \frac{100\text{ Ом}}{3300\text{ Ом} + 100\text{ Ом}} \approx \mathbf{0.044\text{ В} = 44\text{ мВ}}$$

**Зборка (тумблер у OFF):**

```
Батарейка (+) ──── Будь-який отвір Breadboard (наприклад, рядок 5)
                       │
                   [R1 = 3.3 кОм]
                       │
                   Рядок 10 ◄── "Точка Магії": тут рівно ~44 мВ
                       │
                   [R2 = 100 Ом]
                       │
Батарейка (-) ──── Синя лінія GND
```

> **Точка Магії (рядок 10):** між R1 та R2 — це ваш "штучний потоковий потенціал". Вільні отвори цього рядка (10C, 10D, 10E) — готові точки підключення для LTC3108.

### Острів 2: Каскад Збору (LTC3108)

> **Контекст:** LTC3108 використовується в лабораторному прототипі для демонстрації роботи від наддалеких напруг (44 мВ). У виробничій архітектурі LTC3108 **видалено** — EBFC Gen 2.0 на dgrFAD-GDH / Laccase+ZIF-nanozyme генерує >500 мВ, що вище порогу Cold-Start BQ25570 (330 мВ).

**Компоненти:**
- Плата-перехідник з **LTC3108** (Linear Technology)
- Трансформатор **Coilcraft LPR6235-752SMRC** (1:100 — первинна:вторинна)
- Конденсатор **1 нФ** на пін **C1** (зарядна помпа / випрямляч — рекоменд. для 1:100; datasheet «C1 Capacitor»)
- Конденсатор **330 пФ** на пін **C2** (gate-coupling — зв'язує вторинку із затвором)
- Резистор **499 кΩ** паралельно C2 (bleeder проти squegging; datasheet «Squegging»)
- Конденсатор **1 мкФ** (між VAUX та GND)
- Конденсатор **2.2 мкФ** (між VLDO та GND)

#### Анатомія Осцилятора (Фізика)

LTC3108 + трансформатор = гойдалка-резонатор:
1. 44 мВ → первинна котушка трансформатора
2. Трансформатор підсилює через індукцію → повертає поштовх у мікросхему
3. Мікросхема знову штовхає котушку (сильніше) → резонанс
4. Цей цикл × тисячі разів/секунду → напруга зростає з 44 мВ до ~2-3 В
5. Частоту розгойдування задає **індуктивність вторинної обмотки** (+ її паразитна ємність ~30 пФ), а НЕ зовнішній конденсатор (datasheet: f = 1/(2π·√(L·C))). C2 (330 пФ) лише зв'язує обмотку із затвором, C1 (1 нФ) живить зарядну помпу

#### Зборка Острова 2

| Крок | Підключення | Призначення |
|---|---|---|
| GND | Пін GND (LTC3108) → синя лінія | Спільна земля |
| VIN | "Точка Магії" (рядок 10) → пін **VIN** (LTC3108) | Вхід 44 мВ |
| Трансф. первинна (пін 1) | рядок VIN (рядок 10) → трансформатор пін **1** | Початок первинної котушки |
| Трансф. первинна (пін 4) | Трансформатор пін **4** → пін **SW** (LTC3108) | Кінець первинної котушки (SW = "штовхач") |
| Трансф. вторинна (пін 2) | Трансформатор пін **2** → синя лінія GND | Опора вторинної котушки |
| Конденсатор 1 нФ (C1) | Трансформатор пін **3** ↔ пін **C1** (LTC3108) | Зарядна помпа / випрямляч |
| Конденсатор 330 пФ (C2) | Трансформатор пін **3** ↔ пін **C2** (LTC3108) | Gate-coupling |
| Bleeder 499 кΩ | пін **C2** ↔ GND (паралельно C2) | Анти-squegging (datasheet) |
| Буфер VAUX | Конденсатор 1 мкФ між **VAUX** та GND | Фільтр проміжного виходу |
| Буфер VLDO | Конденсатор 2.2 мкФ між **VLDO** та GND | Фільтр LDO виходу |
| Вихід | Пін **VOUT** (LTC3108) → перемичка → Острів 3 | ~3.3-5 В стабілізованих |

> Піни 1, 4 (первинна обмотка) та 2, 3 (вторинна обмотка) — відповідно до datasheet Coilcraft LPR6235.

### Острів 3: Менеджер та Резервуар (BQ25570 + Lab Storage Cap)

> 🔴 **Reality Check — Пастка 31-го Дня (РЕЗЮМЕ ФІЗИКИ):**
>
> Якщо студент зібрав Острів 1 (44 мВ divider) і Острів 3 з виробничим 0.47 Ф іоністором, **семестр закінчиться раніше, ніж блимне світлодіод**. Чому — нижче.
>
> **Розрахунок за теоремою Тевеніна:**
> ```
> V_th = 44 мВ                              (вихід дільника під навантаженням 0)
> R_th = R1 ∥ R2 = 3300 × 100 / 3400 ≈ 97 Ω  (внутрішній опір дільника)
> P_max = V_th² / (4 R_th) = 0.044² / 388 ≈ 5 µW    (макс. передача потужності, теорема Якобі-Тевеніна)
> P_to_cap ≈ 5 µW × η_LTC3108(~30%) × η_BQ25570_boost(~70%) ≈ 1 µW
> ```
>
> **Енергія для повного заряду 0.47 Ф до 3.4 В:**
> ```
> E = ½ × 0.47 × 3.4² = 2.71 Дж
> t = 2.71 Дж / 1 µW = 2.71 × 10⁶ с ≈ 31 доба
> ```
>
> **Тобто навчальний стенд з виробничим 0.47 Ф = неможливий для одного семестру.** Тому в освітньому setup ми **навмисно зменшуємо ємність зберігача у ~470× — до 1 мФ (1000 µF) low-leakage тантал/полімер**. Виробнича архітектура з 0.47 Ф запускається тільки від справжнього EBFC (>500 мВ, R_int 5–20 кΩ → P ≈ 15–30 µW), а не від 44 мВ-симулятора.

**Компоненти (освітній стенд):**
- Модуль **CJMCU-25570** (BQ25570 breakout, червона плата)
- **Лабораторний накопичувач — 1 мФ (1000 µF) low-leakage tantalum/polymer** (наприклад Kemet T520 або Panasonic SP-Cap, ESR < 50 мΩ, leakage ≤ 1 µA, напруга ≥ 10 V)
  - ❌ **Заборонено:** звичайний алюмінієвий електроліт 1000 µF — leakage 5–10 µA з'їсть весь вхідний ~1 µW, cap ніколи не зарядиться
  - ❌ **Заборонено:** використовувати виробничий 0.47 Ф EDLC — час заряду ~31 доба (див. блок вище)

> ⚠️ **Полярність танталового конденсатора:** Маркуванням смужки/«+» на корпусі позначається **плюс** (на відміну від алюмінієвих електролітів, де смужка = мінус!). При переплутуванні полярності тантал **може спалахнути** (failure mode: thermal runaway).

> 💡 **Опціональне покращення для коротших лаб-сесій (≤ 30 хв):** замінити дільник Острова 1 з 3.3kΩ / 100Ω (= 44 мВ, R_th 97Ω) на **6.5kΩ / 1kΩ** (= 200 мВ, R_th 870Ω). Це підносить V_in вище мінімального startup LTC3108 з більшим запасом і піднімає P_max до ~11.5 µW. Демонструє той самий принцип «ультранизьковольтного енергозбору», але з реалістичним temp-of-lab.

**Зборка:**

```
LTC3108 VOUT ──── пін VIN_DC (BQ25570)      ← Вхід енергії від Острова 2
Синя лінія   ──── пін GND (BQ25570)          ← Земля
Іоністор (+) ──── пін VBAT (BQ25570)         ← Накопичувач (резервуар)
Іоністор (-) ──── Синя лінія GND             ← Мінус іоністора = земля

BQ25570 VOUT ──── перемичка → Острів 4       ← 3.3V для мікроконтролера
```

**Що відбувається фізично:**
- BQ25570 бере мікрокраплі енергії від LTC3108 і по краплях заливає їх в іоністор
- Іоністор повільно заряджається (0 → 3.4V → 5.5V)
- Коли VSTOR ≥ 3.4V → BQ25570 відкриває Buck-конвертер → VOUT = 3.3V

### Острів 4: Мозок та Радіо

**Зборка:**

```
BQ25570 VOUT ──── пін 3V3 (LoRa-E5 mini)    ← Живлення від "дерева"
Синя лінія   ──── пін GND (LoRa-E5)          ← Земля
```

> Розмістіть плату LoRa-E5 на краю Breadboard для зручного підключення Type-C (прошивка) та ST-LINK (SWD debug).

### Тестовий Запуск (Перший Холодний Старт)

**Послідовність:**

1. Зберіть усі острови. Перевірте всі GND-з'єднання в синій лінії
2. Підключіть мультиметр (щупи на ніжки **1 мФ танталового cap**). Показання = **0 В**
3. Клацніть тумблер батарейки → **ON**
4. На дисплеї мультиметра ви побачите:
   ```
   0.1 В ... 0.3 В ... 0.8 В ... 1.5 В ... 2.2 В ... 3.0 В ... 3.4 В
   ```
   Конденсатор повільно, мілівольт за мілівольтом, накопичує енергію
5. **Очікуваний час до VBAT_OK (3.4 В) — за конфігураціями:**

   | Конфігурація | V_source | P_to_cap (реал.) | C_storage | t_до_3.4В |
   |---|---|---|---|---|
   | Базова (44 мВ + 1 мФ tant) | 44 мВ | ~1 µW | 1 мФ | **~95 хв** (1 пара) |
   | Прискорена (200 мВ + 1 мФ tant) | 200 мВ | ~4–6 µW | 1 мФ | **~15–25 хв** |
   | Multi-session (44 мВ + 10 мФ tant) | 44 мВ | ~1 µW | 10 мФ | ~16 год (overnight) |
   | ❌ Виробничий cap на тестовому source (44 мВ + 0.47 Ф EDLC) | 44 мВ | ~1 µW | 0.47 Ф | **~31 доба** (не для лаб) |

6. Коли VSTOR ≥ 3.4V → BQ25570 подасть 3.3V на LoRa-E5 → **блимне світлодіод**

> **Ваша система ожила від 44 мілівольтів.** Енергії, якої б не вистачило навіть на один піксель дисплея MacBook. Але тільки тому, що ми зменшили накопичувач у 470 разів проти виробничого EDLC, який чекає на справжній EBFC (>500 мВ, P ≈ 15–30 µW).

```

               │               │                   │

               │           VIN─┘ SW──[Xfmr pin4]   │
               │           C1──[1nF]───[Xfmr pin3] │
               │           C2──[330pF]──[Xfmr pin3]│
               │           (bleeder 499k: C2↔GND)  │
               │           GND─────────────────────┼─── СИНЯ ЛІНІЯ GND
               │           VOUT──────────────────┐  │
               │                                 │  │
               │                        [BQ25570] │  │
               │                        VIN_DC───┘  │
               │                        VBAT──[0.47F]─┤
               │                        GND───────────┤

               │                              │       │

               │                    3V3──────┘       │
               │                    GND──────────────┘

## 🔄 Перехід до Виробничої Архітектури

Коли студент/лаборант хоче перейти від цього навчального стенду до реальної виробничої схеми:

1. **Видалити Острів 1 і Острів 2** (батарейка AA, дільник 44 мВ, LTC3108, трансформатор Coilcraft, C1/C2 обв'язка)
2. **Замінити вхід BQ25570 (VIN_DC):** з'єднати безпосередньо з виходом EBFC Gen 2.0 (Ti-6Al-4V анкер з dgrFAD-GDH / Laccase+ZIF-nanozyme, `01_03`)
3. **Замінити навчальний 1 мФ tantalum на виробничий 0.47 Ф EDLC** — цей крок безпечний лише тому, що EBFC дає ~15–30 µW (а не 1 µW з симулятора 44 мВ), тож виробничий cap зарядиться за хвилини, не дні. Перевірка часу заряду — у `02_03 §10.4` Тестовий Запуск.
4. **Перевірити cold start:** виміряти R_int EBFC (див. [`02_03 §1.5`](02_03_BQ25570_MPPT_Nano_Power)). Якщо R_int > 12 кΩ — повернути LTC3108 як cold-start preboost (DNP footprint у PCB).
5. **Перепрограмувати резистори BQ25570** з Li-Po defaults на supercap-targets (`02_03 §4`) — переконатися, що R_OC1/R_OC2 іменуються за TI convention (`02_03 §4.А`: R_OC1 = VOC_SAMP→GND), інакше фракція MPP стане 35% замість 65%.
