# 08_04: ЧДТУ — Міжкафедральне Академічне Партнерство

## 🎯 Мета

Формалізація академічної співпраці з **Черкаським державним технологічним університетом (ЧДТУ)** за трьома напрямами:

1. **Data Science, математична статистика та оптимізація** — Кафедра статистики та прикладної математики (доц. Карапетян А.Р.)
2. **Радіофізика та електродинаміка** — Факультет електронних технологій і робототехніки, ФЕТР (декан Гончаров А.) та кафедра радіотехніки
3. **Акустична мехатроніка та приладобудування** — Кафедра приладобудування, мехатроніки та комп'ютеризованих технологій, ПМКТ (проф. Базіло К.В., проф. Бондаренко М.О.)

ЧДТУ (колишній ЧІТІ) — історично найсильніша технічна база Черкаського регіону. Три кафедри ЧДТУ покривають повний цикл від апаратної верифікації акустичного сигналу (ПМКТ) через оптимізацію радіоканалу (ФЕТР) до статистичного аналізу масивів біотелеметрії (Карапетян). Silken Net надає всім трьом кафедрам готовий міжкафедральний R&D-полігон для спільних публікацій та грантових заявок.

> **Контекст:** Архітектор Silken Net (Олексій Лукін) — випускник школи-колегіуму «Берегиня» (Черкаси, 1995–2005), де Анаіт Радіківна Карапетян була його класним керівником протягом семи років. У 2023 році А.Р. Карапетян звернулась із запитом щодо можливих спільних Data Science проєктів. Silken Net — це відповідь на той запит: реальний DeepTech-полігон для наукових досліджень рівня Scopus Q1/Q2.

> **Роль у MOIC:** `08_04` закриває в Mission-Oriented Innovation Cluster (див. [`08_03` §0](08_03_Joint_Publications_and_IP_Strategy)) ортогональну нішу **Hard Science Layer — data / RF / акустика**: Карапетян (статистика, Ляпунов/RQA, anomaly detection), Гончаров/ФЕТР (радіофізика, EMC, VNA), Базіло+Бондаренко/ПМКТ (п'єзохарактеризація, акустичний стенд). Ця ніша **не дублює** хімію/фізику ЧНУ ([`08_01`](08_01_University_R_and_D_Protocols)), кібернетику ФОТІУС ([`08_02`](08_02_Cybernetic_and_Mathematical_Validation)) або біохімію ЧМА ([`08_06`](08_06_CHMA_Biomedical_Integration)). Перетини з ФОТІУС (наприклад, статистика vs Data Mining) формалізовані як міжуніверситетська синергія в [§8 цього документа](#8-міжуніверситетська-синергія-чдту--чну-фотіус) та у Статтях 15–22 ([`08_03` §1C](08_03_Joint_Publications_and_IP_Strategy)).

### 1.2. Декан Артем Гончаров — Радіофізика та Електродинаміка (ФЕТР)

**Посада:** Декан факультету електронних технологій і робототехніки (ФЕТР) ЧДТУ
**Структурний підрозділ:** Кафедра радіотехніки ФЕТР
**Науковий профіль:** Телекомунікаційні системи та технології, радіотехнічні пристрої та засоби, електромагнітна сумісність (EMC), антенно-фідерні пристрої
**Лабораторна база ФЕТР:** Кафедра радіотехніки ЧДТУ має підтверджену лабораторну інфраструктуру для вимірювань у мікрохвильовому діапазоні (VNA-клас), стенди EMC та поле для натурних вимірювань поширення радіосигналу — профільна компетенція факультету, що готує фахівців спеціальності 172 «Телекомунікації та радіотехніка».

**Точка перетину зі Silken Net:**

Silken Net використовує **LoRa 868 МГц** у найскладнішому для радіохвиль середовищі — вологому лісі (кора дерева ε ≈ 10–20, σ ≈ 0.1–0.5 S/m поглинає радіосигнал). Архітектурний Pivot проєкту відмовився від зовнішньої штирьової антени — SMD-антена захована під PEEK-радомом (IP68). Це створює ризики відбитої хвилі (VSWR) та спалення радіотракту STM32WLE5JC.

Факультет ФЕТР ЧДТУ спеціалізується на телекомунікаціях та радіотехнічних системах. Лабораторії ФЕТР мають VNA (Vector Network Analyzer) та обладнання для EMC-тестування, що дозволяє провести повний аудит Physical Layer.

**Зв'язок із Косенюком (ЧНУ ФОТІУС):**

Доц. Косенюк Г.В. (ЧНУ, [`08_02`](08_02_Cybernetic_and_Mathematical_Validation) §1.3) — військовий радіотехнік з 50+ роками досвіду — виконує розрахунок імпедансу, 3D-діаграми спрямованості та Link Budget. Гончаров та кафедра радіотехніки ФЕТР надають **лабораторну інфраструктуру та експериментальну верифікацію** розрахунків Косенюка:

| Косенюк (ЧНУ) — Розрахунок | Гончаров / ФЕТР (ЧДТУ) — Верифікація |
|------------------------------|---------------------------------------|
| LC-ланцюг узгодження (П/Т-фільтр) для VSWR < 1.5 | VNA-вимір S11-параметра реальної зборки у PEEK-корпусі |
| Link Budget LoRa у лісі (SF=7–9, запас > +55 дБ) | Натурні вимірювання propagation loss у реальному лісі |
| 3D-діаграма спрямованості (FEKO/CST моделювання) | Вимірювання реальної діаграми в анехоїдній камері (або open-field) |
| CE/FCC pre-compliance | EMC-тестування емісій у лабораторії ФЕТР |

**Конкретний R&D-запит (три завдання):**

**Завдання А: Експериментальна верифікація імпедансу SMD-антени**

```
Стенд ФЕТР:
  1. VNA-вимір S11 реальної зборки: SMD-антена + PEEK-кришка + O-ring + Ti-анкер
  2. Вимір при сухій та вологій корі (імітація дощу) → діапазон VSWR
  3. Верифікація LC-узгодження Косенюка: КСВ < 1.5 у смузі 868 ± 1 МГц
  4. Ітеративне тестування: 3–5 варіантів PEEK-кришки (товщина 1.5/2.0/2.5 мм)
```

**Завдання Б: Натурні вимірювання Link Budget у лісовому масиві**

```
Методика:
  1. Два STM32WLE5JC прототипи (Soldier → Queen): відстань 50/100/150/200/250 м
  2. Замір RSSI та PER (Packet Error Rate) для SF=7, 8, 9, 10
  3. Умови: сухий день, мокрий день, зима (без листя), літо (повна крона)
  4. Результат: калібрований path loss model для firmware (оптимальний SF per дальність)
```

**Завдання В: EMC-тестування для CE/FCC pre-compliance**

```
Мета: Підтвердити, що LoRa TX +22 dBm під PEEK-радомом:
  1. Не перевищує duty cycle 1% (ETSI EN 300 220, EU)
  2. Spurious emissions < -36 dBm за межами ISM-смуги
  3. Conducted emissions від BQ25570 MPPT не інтерферують з RX
```

### 1.3. Проф. Костянтин Вікторович Базіло та Проф. Максим Олексійович Бондаренко — Акустична Мехатроніка та Приладобудування (ПМКТ)

**Кафедра:** Приладобудування, мехатроніки та комп'ютеризованих технологій (ПМКТ) ЧДТУ

**Базіло К.В.:** Доктор технічних наук, професор. Науковий профіль — резонансні характеристики п'єзокерамічних дискових та циліндричних перетворювачів (радіальні та товщинні моди коливань), побудова еквівалентних електричних схем п'єзоелементів, імпедансна спектроскопія. Публікується у MDPI Sensors (Q1) та Eastern-European Journal of Enterprise Technologies (Q2). **Пряме перетворення для Silken Net:** метод EIS-характеризації (Electrochemical/Electrical Impedance Spectroscopy) п'єзодиска — це саме те, що потрібно для Завдання Б §1.3: визначення резонансних частот сенсора у діапазоні 25–150 кГц та його чутливості при -20°C..+50°C.

**Бондаренко М.О.:** Доктор технічних наук, професор. Спеціалізація — акустична емісія (AE, Acoustic Emission), прецизійні вібраційні вимірювання, мікродеформації поверхонь. **Пряме перетворення для Silken Net:** метод AE є галузевим стандартом виявлення кавітаційних мікроемісій ксилеми (кавітація при посуховому стресі генерує характерні burst-сигнали у діапазоні 100–400 кГц — Bréda et al., Tyree & Sperry); Бондаренко знає цей клас сигналів та умови їх реєстрації через тверде тіло, що безпосередньо застосовне до детекції через Ti-6Al-4V гіроїд.

**Точка перетину зі Silken Net:**

Система Silken Net використовує **п'єзосенсор** для акустичної детекції кавітації ксилеми (ультразвукові емісії при виникненні повітряних бульбашок у судинах дерева — маркер посухового стресу). Титановий гіроїд (TPMS, пористість 65%) теоретично виконує роль **пасивної фононної лінзи**: гасить макрошум (вітер, тертя гілок, дощ у діапазоні < 20 кГц) та фокусує ультразвукові мікроемісії кавітації (~25–150 кГц) на п'єзоелектричний елемент при нульовому споживанні струму.

Кафедра ПМКТ — це лабораторія суворого приладобудування з обладнанням для роботи з п'єзоелементами, мікродеформаціями та акустичними вимірюваннями. Базіло та Бондаренко можуть інструментально підтвердити або спростувати ефект фокусування звуку гіроїдною структурою.

**Зв'язок із Косенюком (ЧНУ) та TinyML Pipeline:**

| Компонент Pipeline | Учасник | Роль |
|--------------------|---------|------|
| Фононна лінза (гіроїд → п'єзосенсор) | **Базіло + Бондаренко (ЧДТУ ПМКТ)** | Інструментальна валідація Compute-by-Geometry |
| ADC/DMA 16 кГц → TinyML inference | Ярмілко (ЧНУ, [`08_02`](08_02_Cybernetic_and_Mathematical_Validation) §1.1) | SPI/DMA оптимізація firmware |
| Стохастична фільтрація delta_t | Косенюк (ЧНУ, [`08_02`](08_02_Cybernetic_and_Mathematical_Validation) §1.3) | Kalman Filter для шумозниження |
| Статистичний аналіз акустичних даних | Карапетян (ЧДТУ, §1.1) | Характеризація розподілів acoustic_events |

**Чому саме Базіло + Бондаренко:**
- Базіло визначає **резонансну частоту та чутливість п'єзосенсора** через EIS (завдання Б) — без цього невідомо, на якій частоті налаштовувати TinyML-вікно ADC 16 кГц
- Бондаренко застосовує **метод AE (Acoustic Emission)** — галузевий стандарт виявлення кавітаційних burst-сигналів ксилеми (~100–400 кГц, короткі спалахи тривалістю < 1 мс); він знає умови надійної реєстрації таких сигналів через тверде тіло та вплив фонового шуму

**Конкретний R&D-запит (три завдання):**

**Завдання А: Акустичний стенд валідації фононної лінзи (Acoustic Chamber)**

```
Стенд ПМКТ:
  1. Генерація контрольованих акустичних сигналів:
     - Імітація вітрового шуму:      white noise, 0.1–20 кГц, SPL 40–70 дБ
     - Імітація кавітації ксилеми:    burst сигнали, 25–150 кГц, SPL 20–40 дБ
     - Імітація бензопили:            гармоніки 200–6000 Гц, SPL 80–100 дБ
  2. Зразок: Ti-6Al-4V гіроїд **Zone 1 анодної секції** тризонного анкера (пористість 65%, 30–50 мм, вертикальна орієнтація пор — див. [`01_01 §5.5`](01_01_Coaxial_Gyroid_Topology_and_PEEK)) + п'єзосенсор на торці. Тестується саме анодна гіроїдна секція, бо вона має TPMS-структуру і виконує роль фононного фільтра; PEEK-втулка (Zone 2) і катодний фланець (Zone 3) — без TPMS, в акустичному ланцюгу не задіяні
  3. Контрольний зразок: ідентичний п'єзосенсор без гіроїда (bare sensor)
  4. Вимірювання: осцилограф + спектроаналізатор → АЧХ з гіроїдом vs без
  5. Метрика: SNR(кавітація) / SNR(вітер) → коефіцієнт фокусування
```

**Очікуваний результат:**
- Якщо гіроїд дійсно гасить < 20 кГц та фокусує > 25 кГц → **підтвердження** Compute-by-Geometry при 0.0 мкА
- Якщо ефект відсутній або незначний → необхідний перегляд акустичної архітектури (активний фільтр на MCU, DSP preprocessing)

**Завдання Б: Характеризація п'єзоелемента для умов ксилеми**

```
Параметри вимірювань (EIS + AE підхід):
  1. Імпедансна спектроскопія (EIS, метод Базіло):
     - АЧХ та фазо-частотна характеристика: 1 кГц..500 кГц
     - Еквівалентна схема (Butterworth-Van Dyke model): R₁, C₁, L₁, C₀
     - Резонансна/антирезонансна частота → точне налаштування ADC 16 кГц вікна
  2. Чутливість у цільовому діапазоні 25–150 кГц (ксилемна кавітація)
     + 100–400 кГц (AE burst-сигнали, метод Бондаренко)
  3. Вплив T = -20°C..+50°C та вологості (імітація ксилемного середовища)
  4. Рекомендації: тип/розмір п'єзодиска для детекції AE через Ti-хвилевід
```

**Завдання В: Калібрувальний датасет для TinyML**

### 2.2. Масштаб Data Science задач у Silken Net

- **24М пакетів/добу** → потрібна ефективна агрегація та статистичний аналіз

- Кожен запис містить: `vcap`, `temperature`, `delta_t`, `acoustic_events`, `z_value`, `growth_points`, `bio_status`

### 3.2. Атрактор Лоренца — Аналіз Хаотичної Динаміки

Dual Computation Integrity: firmware (Float64) vs backend (Float64 для паритету, BigDecimal доступний). Формальна верифікація precision (Float64 vs RK4), валідність OPTIMAL_Z_TARGET=29.0 та неперервність стану між циклами STOP2 — **ЧНУ ФОТІУС Порубльов** (→ [`08_02` §1.2](08_02_Cybernetic_and_Mathematical_Validation)); задачі #7–13 нижче виконуються на **верифікованих** Z-траєкторіях → Стаття 15 [`08_03`](08_03_Joint_Publications_and_IP_Strategy).
```
id | tree_id | gateway_id | voltage_mv | temperature_c | delta_t |
acoustic_events | bio_status | z_value | growth_points | rssi |
firmware_version | ttl | oracle_status | verified_by_iotex | zk_proof_ref |

```

Партиціонована RANGE по `created_at`. Мільйони записів на добу при масштабі.

### 6.3. Експорт Даних для R

```ruby
# Rails console → CSV для R-аналізу
require "csv"

CSV.open("telemetry_export.csv", "w") do |csv|
  csv << %w[tree_id voltage_mv temperature_c delta_t
            acoustic_events bio_status z_value growth_points created_at]

  TelemetryLog.where(created_at: 1.month.ago..).select(
    :tree_id, :voltage_mv, :temperature_c, :delta_t,
    :acoustic_events, :bio_status, :z_value, :growth_points,
    :created_at
  ).find_each do |log|
    csv << [log.tree_id, log.voltage_mv, log.temperature_c,
            log.delta_t, log.acoustic_events, log.bio_status,
            log.z_value, log.growth_points, log.created_at.iso8601]
  end
end
```

### 8.4. Завдання Виключно для ЧНУ ФОТІУС (без перетину з ЧДТУ)

Наступні напрямки `08_02` не мають паралелей у ЧДТУ і залишаються виключно у компетенції ФОТІУС:

| Напрямок | Науковець ФОТІУС | Чому тільки ФОТІУС |
|----------|-------------------|---------------------|
| SPI/DMA оптимізація MCU | Ярмілко | Апаратна інженерія embedded systems |
| Lightweight Cryptography (ECDH, MAC) | Ярмілко | Безпека IoT-прошивки |
| Арифметичне стиснення payload | Ярмілко | Data compression на MCU |
| Petri net верифікація (firmware + Rails) | Супруненко + Онищенко | Формальні методи верифікації ПЗ |
| Convolution Method (state explosion) | Супруненко | Теоретична CS |
| FEC (Reed-Solomon/Hamming) | Косенюк | Теорія кодування |
| BSP-кластеризація IoT-графу | Бушин | Алгоритмічна кластеризація графів |
| Геометрична валідація гіроїда | Порубльов | Обчислювальна геометрія |
| CFD-симуляції на Akash | Онищенко | Паралельне програмування |
| Master of Logic (Boolean мінімізація) | Любченко | Формальна логіка та верифікація |

> **Примітка:** RF-оптимізація SMD-антени (Косенюк) та CE/FCC/EMC сертифікація тепер є **спільним** напрямком ФОТІУС × ЧДТУ ФЕТР (зона IX матриці §8.1). Косенюк виконує аналітичну частину (FEKO/CST, LC-узгодження, Link Budget), Гончаров та кафедра радіотехніки ФЕТР — лабораторну верифікацію (VNA, натурні виміри, EMC-тестування).

### 8.5. Рекомендації щодо Координації

1. **Спільний семінар (Kickoff):** Провести одноденний семінар ЧДТУ (3 кафедри) + ЧНУ ФОТІУС з демонстрацією Silken Net (forest_simulator + апаратний концепт гіроїда). Мета: взаємне знайомство команд, узгодження форматів даних, визначення спільних публікацій.

2. **Спільний датасет:** Один і той же набір симульованої телеметрії (`bin/forest_simulator`, 1 місяць, 50 дерев) використовується обома університетами як benchmark. Формат CSV — експорт через скрипт секції 6.3.

3. **Quarterly Sync:** Щоквартальна зустріч Архітектор + Карапетян (ЧДТУ) + Гончаров (ЧДТУ ФЕТР) + Базіло (ЧДТУ ПМКТ) + Онищенко/Супруненко (ФОТІУС) для синхронізації результатів та планування спільних публікацій.

4. **Git-based Collaboration:** ЧДТУ R-скрипти → `lib/analytics/r/`, ФОТІУС Python/C → `lib/analytics/python/`, ФЕТР RF-вимірювальні дані (S11, path loss, EMC) → `lib/measurements/rf/`, ПМКТ акустичні калібрувальні дані → `lib/datasets/acoustic_training/`. Всі інтегруються через CI/CD ([`00_07`](00_07_GitHub_Projects_and_IaC_Automation)).

5. **Потрійна Спіраль 2.0:** Модель Осауленка (08_02 §1.7) розширюється з ЧНУ → ЧНУ + ЧДТУ як наукова вершина спіралі. Три кафедри ЧДТУ + ЧНУ ФОТІУС = ширша академічна база для грантових заявок (Horizon Europe, NFDI).

6. **Міжкафедральний ЧДТУ проєкт:** Silken Net як об'єднуючий R&D-полігон для ФЕТР + ПМКТ + кафедри статистики: радіотехніки (ФЕТР) верифікують радіоканал, приладобудівники (ПМКТ) верифікують акустику, статистики (Карапетян) аналізують дані. Це ідеальна основа для отримання інституційних грантів ЧДТУ.
