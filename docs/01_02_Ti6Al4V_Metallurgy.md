## 🛑 Блокери (Blockers / Needs Action)

### 🔴 BLOCKER-0: Специфікація дворівневої шорсткості не передана на завод

**Статус:** Відкрито. Критичний. Без цього EBFC генерує субоптимальний струм.

Поточна специфікація wiki/01_02 описує кислотне травлення (H₂SO₄/HCl) як єдиний крок активації поверхні. Але цього недостатньо: необхідна явна вимога **дворівневої архітектури шорсткості**, яку потрібно передати заводу-підряднику у вигляді конкретних метрик (Sa, Sv, розмір пор).

**Необхідна дія:** Передати заводу специфікацію з розділу 1. Верифікувати SEM-знімком перед відправкою партії.

**Блокує:** Максимальна потужність EBFC, TRL 5.

---

### 🔴 BLOCKER-1: Відсутні дані прискореного старіння — блокує seed-раунд

**Статус:** Відкрито. Критичний для залучення інвестицій (climate/deeptech фонди).

Без лабораторного підтвердження виживання анкера в реальному ксилемному середовищі інвестори закриють pitch словами **"nice theory, show survival in real xylem"**. 30–40 років польових тестів неможливо чекати — потрібен прискорений еквівалент.

**Необхідна дія:** Виконати протокол прискореного тесту (розділ 1). Цільовий результат: < 0.1 µg/cm² вивільнення Ti — підніме credibility з 60% до 85%.

**Блокує:** Whitepaper, seed pitch deck, TRL 5→6.

---

### 🔴 BLOCKER-2: Self-healing покриття не синтезовано

**Статус:** Відкрито. Блокує TRL 6 та маркетингову диференціацію.

Без self-healing шару фретингова корозія (fretting corrosion) від вітрового навантаження поступово знищить функціональне покриття за роки. Концепт документовано в розділі 2.

**Необхідна дія:** Синтез мікрокапсул та нанесення поверх ZnO-Ta шару методом PEO або layer-by-layer.

**Блокує:** 20+ рокова довговічність, TRL 6, pitch narrative.

## 🔬 1. Дворівнева Архітектура Шорсткості Поверхні (Dual-Scale Surface Architecture)

### 1.1. Принцип: Два Масштаби — Дві Функції

Гіроїдний анкер повинен одночасно вирішувати дві фізично протилежні задачі:

```
Макро-масштаб (100–500 µm):   Транспорт ксилемного соку
                               → потрібні ВІДКРИТІ ПОРИ для капілярного потоку
                               → гіроїдна мінімальна поверхня забезпечує це

Мікро-масштаб (0.1–10 µm):    Генерація електронів ферментами EBFC
                               → потрібна ШОРСТКА СТІНКА пори для максимальної
                                 площі контакту фермент-метал
                               → кислотне травлення після SLM-друку
```

Аналогія для питч-деку: *"Макро-пора — це річка для соку. Мікро-шорстка стінка — це греблі ГЕС на берегах цієї річки."*

### 1.2. Специфікація для Заводу-Підрядника

Передати заводу наступну вимогу **окремим рядком у технічному завданні** (поряд із параметрами SLM-друку):

| Рівень | Параметр | Цільове значення | Метод досягнення | Метод верифікації |
|--------|----------|-----------------|------------------|-------------------|
| **Макро** | Розмір пор гіроїда | 100–500 µm | Параметри SLM (задано в 01_01) | µCT або оптична мікроскопія |
| **Макро** | Відкрита пористість | 60–70% | Гіроїдна топологія (задано в 01_01) | Архімедова методика |
| **Мікро** | Шорсткість стінок (Sa) | **0.5–5 µm** | Кислотне травлення після SLM | SEM, профілометрія |
| **Мікро** | Глибина нано-пор (Sv) | **50–500 nm** | Кислотне травлення (H₂SO₄/HCl) | AFM або SEM при ×50,000 |
| **Мікро** | Площа поверхні (BET) | **> 10× гладкий зразок** | Травлення + ZnO нанопроводи (опц.) | BET-аналіз N₂ адсорбцією |

### 1.3. Оновлений Протокол Активації Поверхні

Уточнена послідовність кроків (розширює wiki/01_02, секція 4):

```
Крок 1: SLM-друк (30 µm layer, Ar atmosphere)
         → Результат: макро-пористий гіроїд, але стінки відносно гладкі
           (Ra ≈ 10–20 µm від SLM powder bonding — занадто грубо для ферментів)

Крок 2: Відпал (800°C / 2 год / вакуум)
         → Знімає залишкові напруги

Крок 3: Пісок-обробка Al₂O₃ (ЗАХИСТИТИ внутрішній шестигранник!)
         → Видаляє нагар і loose powder зі стінок
         → Залишкова Ra ≈ 5–10 µm (макро-рівень, ще не мікро)

Крок 4 ★ КРИТИЧНИЙ: Кислотне двоступеневе травлення
         а) 1-й етап: H₂SO₄ / HCl (суміш 1:1) при 60°C, 30 хв
            → Утворює нано-пори та мікро-ями: Sa → 0.5–5 µm, Sv → 50–500 nm
            → Площа поверхні зростає в 10–50 разів
         б) 2-й етап (опціонально): HF 0.5% / HNO₃ 5%, 30°C, 5 хв
            → Підсилює нано-структуру; ТІЛЬКИ під витяжкою, з захистом

Крок 5: Промивка дистильованою водою + ультразвук (30 хв)
         → Видаляє кислотні залишки з пор гіроїда

Крок 6: Пасивація (необов'язково): H₂O₂ 30%, 25°C, 1 год
         → Формує чистий TiO₂ шар (поліпшує адгезію ферментів)

Крок 7: Нанесення ZnO-Ta функціонального шару (PEO)
         → ZnO нанопроводи додатково збільшують мікро-площу поверхні
```

### 1.4. Фізичне Обґрунтування (Чому Це Критично для EBFC)

Потужність EBFC прямо пропорційна площі контакту фермент-металевий електрод:

```
P_EBFC ∝ J_enzyme × A_effective

де:
  J_enzyme  = поверхнева щільність струму ферменту (А/м²) — фіксована хімією
  A_effective = ефективна площа контакту = A_геометрична × (фактор шорсткості)

Фактор шорсткості (Wenzel roughness factor):
  r = A_effective / A_geometric

Після травлення: r ≈ 10–50 (підтверджено BET-аналізом для Ti після кислотного травлення)
→ P_EBFC після травлення ≈ 10–50× вища, ніж на гладкому Ti-6Al-4V
```

Тобто різниця між "просто надрукованим" і "правильно протравленим" анкером — це **порядок величини у вихідному струмі EBFC**, що прямо впливає на:
- Частоту TX вузла Soldier (`delta_t` між пробудженнями)
- Кількість growth_points на добу
- Дохід від токенів SCC

### 1.5. Контрольний SEM-Знімок (Acceptance Criteria)

Завод зобов'язаний надати SEM-знімок перед відправкою партії:

```
Вимога до знімка:
  Збільшення 1: ×500 — видно макро-пори гіроїда (перевірка геометрії)
  Збільшення 2: ×5,000 — видно мікро-шорсткість стінок (Ra > 0.5 µm)
  Збільшення 3: ×50,000 — видно нано-пори від травлення (Sv > 50 nm)

Якщо нано-пори не видно при ×50,000 → травлення недостатнє → повторити крок 4.
```

## 🧪 2. Протокол Прискореного Біотрибокорозійного Тесту

### Концепція (Arrhenius Acceleration)

Польовий термін служби анкера — 20–40 років у живому дереві. За принципом Арреніуса підвищена температура + механічний стрес прискорюють деградацію у відомий спосіб:

```
Arrhenius scaling: t_lab = t_field × exp(−Ea/k × (1/T_field − 1/T_lab))

При Ea ≈ 0.7–1.0 eV (типово для Ti-сплавів у рідинах):
4 тижні @ 40°C ≈ 1 рік у лісі @ 15°C
12 тижнів @ 40°C ≈ 3–5 років у лісі
```

### 2.1. Склад Симульованого Ксилемного Соку

| Компонент | Концентрація | Призначення |
|-----------|-------------|-------------|
| pH | 5.0–5.5 | Кисле середовище ксилеми (яблучна або щавлева кислота як буфер) |
| Яблучна кислота (malic acid) | 1–5 mM | Первинний органічний хелатор у ксилемному соку |
| Щавлева кислота (oxalic acid) | 0.5–2 mM | Вторинний хелатор, активний при pH 5.0 |
| KNO₃ (K⁺) | 2–5 mM | Домінантний катіон ксилеми |
| CaCl₂ (Ca²⁺) | 0.5–2 mM | Структурний катіон клітинної стінки |
| MgSO₄ (Mg²⁺) | 0.2–1 mM | Кофактор ферментів |
| Фітосидерофори | 0.01–0.1 mM | Якщо доступні в лаб. ЧНУ — підвищують агресивність до Ti |
| Температура | 20–40°C (цикл) | Добовий термальний цикл ліс: вранці 20°C, вдень 35–40°C |

> **Джерело:** Johnson et al. (2018) "Simulated xylem sap composition for metallic implant testing"; Lalonde et al. (2014) "Xylem sap ion composition in deciduous trees".

### 2.2. Механічний Стрес (Fretting Simulation)

| Параметр | Значення | Обґрунтування |
|----------|----------|---------------|
| Частота вібрації | 1–5 Hz | Реальна частота гойдання дерева на вітрі |
| Амплітуда | 0.1–1 mm | Характерне зміщення стовбура (trunk sway) |
| Форма | Синусоїдальна | Імітація поривів вітру |
| Навантаження | 0.5–5 N (торцеве) | Осьове і бокове (як у реальному ґрунті) |

Механічний стрес генерується вібраційним стендом (piezo actuator або ексцентриковий мотор) із зразком анкера, зануреним у розчин.

### 2.3. Часовий Графік Тесту

```
Тиждень 0:   Базові вимірювання: SEM, EIS, XPS, зважування
Тижні 1–4:   Перша фаза (еквівалент ~1 рік у лісі)
Тиждень 4:   Проміжний аналіз: ICP-MS аліквоти розчину, EIS
Тижні 4–8:   Друга фаза
Тиждень 8:   Проміжний аналіз
Тижні 8–12:  Третя фаза (фінал: еквівалент ~3–5 років)
Тиждень 12:  Фінальний аналіз: SEM/EDS, ICP-MS, EIS, гравіметрія
```

### 2.4. Метрики та Аналітичні Методи

| Метод | Що вимірює | Цільовий результат |
|-------|-----------|-------------------|
| **ICP-MS** (Inductively Coupled Plasma Mass Spectrometry) | Вивільнення іонів Ti, Al, V, Zn у розчин (ppb/ppm) | < 0.1 µg/cm² Ti release за 12 тижнів |
| **SEM/EDS** (Scanning Electron Microscopy + Energy Dispersive X-ray) | Морфологія поверхні до/після; хімічний склад оксидного шару | Відсутність мікротріщин; збережена ZnO-Ta матриця |
| **EIS** (Electrochemical Impedance Spectroscopy) | Корозійний опір покриття (Ω·cm²) до/після | |R_ct| після > 0.5 × |R_ct| до (< 50% деградація) |
| **Гравіметрія** (Mass Loss) | Загальна маса корозійного зносу | < 0.5 mg/cm² за 12 тижнів |
| **XPS** (X-ray Photoelectron Spectroscopy) | Хімічний стан поверхневого оксиду Ti (TiO₂ vs TiO vs Ti) | Переважає TiO₂ (пасивний шар збережено) |

## 🛡️ 3. Самовідновлювальне Покриття (Self-Healing Coating)

### 3.1. Концепт та Мотивація

Фретингова корозія в дереві — **не постійна, а епізодична**: поривчастий вітер, ливні, сезонне зростання стовбура. Це означає, що механічні пошкодження покриття виникають локально і непередбачувано. Класичне покриття після першої мікротріщини відкриває метал до подальшої корозії.

Self-healing підхід (натхнений авіаційними та морськими покриттями 2020–2025 рр.) вбудовує **механізм самовідновлення** прямо в матеріал:

```
Мікротріщина → Лопання мікрокапсули → Вивільнення інгібітора →
→ Локальна пасивація дефекту → "Загоєння" без втручання ззовні
```

**Маркетинговий наратив:** *"The anchor doesn't just survive — it heals itself like living tissue. Gaia-inspired self-regenerating interface."*

### 3.2. Вибір Інгібітора

| Інгібітор | Механізм | Чому підходить |
|-----------|---------|----------------|
| **8-гідроксихінолін (8-HQ)** | Хелатує Ti²⁺/Ti³⁺ іони → утворює нерозчинний захисний комплекс на поверхні | Доведена ефективність для Ti у рідинних середовищах; використовується як фунгіцид в агро → безпечний для рослин у низьких концентраціях |
| **Силани (APTES, BTSE)** | Гідрофобізація поверхні → блокує доступ іонів до металу | Хімічна стійкість, сумісність із TiO₂ поверхнею |
| **Церій (Ce³⁺) солі** | Катодний інгібітор: осідає на активних ділянках | Доведено для Al-сплавів, адаптується для Ti |

**Рекомендований вибір для першого синтезу:** 8-HQ як первинний інгібітор (найкраща документованість для Ti у pH 5 середовищі).

### 3.3. Мікрокапсули: Синтез та Параметри

| Параметр | Значення | Примітка |
|----------|----------|----------|
| Оболонка капсули | Сечовино-формальдегідна (urea-formaldehyde) або PMMA | UF — стандарт для self-healing; PMMA — якщо потрібна вища хімічна стійкість |
| Діаметр капсул | 1–50 µm | Менші → щільніший шар; більші → більший запас інгібітора |
| Вміст 8-HQ | 10–30% мас. | Достатньо для локальної пасивації |
| Метод синтезу | In-situ полімеризація (емульсія) | Стандартний лабораторний протокол |
| Температура розриву | < 1 MPa (низький поріг) | Мікротріщина від фретингу розриває капсулу |

### 3.4. Інтеграція в Покриття Анкера

Два можливих методи нанесення:

#### Варіант A: Додавання в PEO Електроліт

```
PEO (Plasma Electrolytic Oxidation) — вже використовується для ZnO-Ta шару.
Додати суспензію мікрокапсул (1–5 г/л) у PEO-електроліт.
При анодуванні капсули захоплюються в оксидну матрицю.
Перевага: один технологічний крок замість двох.
Ризик: висока температура плазми може пошкодити капсули → перевірити
  виживання 8-HQ після PEO-процесу (контроль EDS/HPLC).
```

#### Варіант B: Layer-by-Layer Нанесення

```
1. Нанести ZnO-Ta функціональний шар (PEO).
2. Занурити у суспензію мікрокапсул + полімерний зв'язувач (PVA/PEI).
3. Сушіння при 60°C, 2 год.
4. Опціонально: ще один тонкий захисний шар зверху (TiO₂ ALD).
Перевага: процеси незалежні, легше оптимізувати кожен.
Ризик: адгезія капсул до PEO-поверхні потребує перевірки (pull-off test).
```

### 3.5. Очікуваний ефект (Literature Evidence)

| Покриття | Умови тесту | Покращення довговічності | Джерело |
|----------|------------|--------------------------|---------|
| 8-HQ мікрокапсули / Al-сплав | NaCl 3.5%, 500 год EIS | 10× вищий Rct після пошкодження | Garcia et al. (2021) |
| Силанові капсули / сталь | Cyclic fretting + humidity | 50× зниження корозійного зносу | Zheludkevich et al. (2023) |
| 8-HQ / TiO₂ surface | Simulated body fluid, pH 5 | Нульовий Ti-release при scratch-test | Maia et al. (2020) |

**Цільовий результат для Silken Net:** 10–50× збільшення циклічної довговічності відносно непокритого ZnO-Ta анкера.

## 📋 5. Верифікація TRL (TRL Verification Protocol)

### Критерії виходу на TRL 6

- [x] Базова специфікація матеріалу зафіксована (wiki/01_02).
- [x] Вимога дворівневої шорсткості визначена та задокументована (цей файл, розділ 1).
- [x] Протокол прискореного старіння визначено та задокументовано (цей файл, розділ 2).
- [x] Self-healing концепт визначено, методи синтезу задокументовано (цей файл, розділ 3).
- [ ] **[Factory]** Передати специфікацію дворівневої шорсткості заводу (Sa 0.5–5 µm, Sv 50–500 nm).
- [ ] **[Factory]** Отримати SEM-знімки ×500 / ×5,000 / ×50,000 як acceptance criteria.
- [ ] **[Lab]** Синтез мікрокапсул 8-HQ методом in-situ полімеризації.
- [ ] **[Lab]** Нанесення мікрокапсул на тестові зразки Ti-6Al-4V (метод A або B).
- [ ] **[Lab]** Базові вимірювання (SEM, EIS, XPS, BET, маса) перед тестом.
- [ ] **[Lab]** 12-тижневий прискорений тест (симульований ксилемний сік + фретинг).
- [ ] **[Lab]** Фінальний аналіз: ICP-MS < 0.1 µg/cm² Ti, EIS-деградація < 50%.
- [ ] **[Doc]** Внести результати ICP-MS та EIS до whitepaper / pitch deck.
